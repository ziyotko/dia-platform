## 一、系统概述

门户统一管理后台是一个集**内容管理、内容审核、数据统计、站点静态化、组织权限与审计**于一体的 Web 管理系统。系统主要能力包括：

- **复杂组织机构管理**：机构（分支机构）→ 部门 → 用户的树形组织结构；
- **统一内容管理**：文章（图文 / 视频 / 数据 / 报刊）、广告、友链、模板、栏目、分类、标签；
- **内容审核流程**：文章按栏目配置的多级线性审核（发起 → 部门负责人/角色/指定成员逐节点审批）；
- **站点静态化**：对接外部静态化程序，批量 / 单页生成网站 HTML；
- **多角色权限控制**：管理员、内容审核、内容作者等角色，按菜单树分配权限；
- **操作日志审计**：操作日志 + 登录日志全程留痕。

**技术构成（仅作了解）**：前端基于 Vue 3 + TypeScript + Element Plus；后端提供 REST API；静态化由独立外部程序完成。菜单与页面权限由后端菜单树动态生成，登录后自动按角色加载。

### 1.1 访问方式

在浏览器中打开部署地址（管理后台页面）。系统通常部署于 Nginx 站点子路径下，实际地址请以管理员提供的为准。

### 1.2 浏览器要求

建议使用主流现代浏览器（Chrome / Edge / Firefox 等）的最新版本，并开启 JavaScript 与 Cookies，以获得完整功能与最佳体验。

## 二、登录与账号

### 2.1 登录页

打开系统地址后进入登录页面，页面分为左右两部分：

- **左侧品牌区**：展示系统 Logo、系统名称（如"门户一体化统一管理后台"）与功能亮点列表（复杂组织机构管理 / 统一内容管理 / 站点静态化 / 多角色权限控制 / 操作日志审计）。
- **右侧登录区**：标题"欢迎回来"，副标题"登录一体化统一管理后台"。
- **页面底部**：展示版权信息与 ICP 备案信息（若系统已配置）。

### 2.2 登录步骤

1. 输入**用户名**（如 `admin`）；
2. 输入**密码**（密码框右侧眼睛图标可切换明文显示）；
3. 输入**验证码**（图形验证码，输入框与验证码图片并列显示）；
   - 看不清时**点击验证码图片可刷新**；
4. 点击 **登 录** 按钮（或输入完成后按回车键）；
5. 登录成功后自动进入管理首页；失败时页面会自动刷新验证码并提示错误原因。

> **提示**：验证码区分大小写，请按图片所示输入。

### 2.3 内置账号与角色（初始）

系统启动初始化时创建以下默认账号，**初始密码均为 `1qaz@WSX`**，首次登录后请务必前往"个人中心"修改密码：

| 登录账号 | 默认用户名 | 角色 | 说明 |
| --- | --- | --- | --- |
| `admin` | 管理员 | 管理员 | 拥有全部功能与数据权限（内置保护账号，不可删除） |
| `reviewer` | 内容审核 | 内容审核 | 负责文章审核（作为流程审批人时处理待审事项） |
| `author` | 内容作者 | 内容作者 | 仅可管理自己创作的内容，需审核通过后发布 |

> 角色 ID 越小权限越高（1 管理员 > 3 内容审核 > 4 内容作者）。普通用户在给他人分配角色或查看他人角色时，只能操作**权限不高于自己**的角色。
>
> 说明：原内置的「普通管理员（`admin`）」角色已**下线移除**，系统不再创建 `operator` 账号。若需要介于管理员与审核/作者之间的管理角色，请到「系统配置 → 角色管理」新建角色，并在「分配权限」中按需勾选菜单。

### 2.4 忘记密码

系统不提供自助找回密码功能。若忘记密码，请联系系统管理员处理；密码的修改由用户本人在"个人中心 → 修改密码"完成，或由管理员重置账号数据。

## 三、主界面与通用操作

登录后进入主界面（布局骨架），自上而下 / 自左而右依次为：

### 3.1 左侧导航栏（侧边栏）

- 顶部为 Logo 与文字"**统一管理后台**"；
- 下方为**菜单树**：目录节点可展开收起（同一时间只展开一个目录），菜单节点点击后进入对应功能页；
- 菜单是否可见取决于当前用户被分配的角色权限；
- 若菜单为外部链接（`http/https` 开头），点击将在新窗口打开；
- 再次点击**当前所在菜单**会触发页面刷新（重新加载数据）。

**折叠侧边栏**：点击顶栏左侧的折叠按钮（展开时显示"折叠"图标、收起时显示"展开"图标），可在 220px 与 64px 宽度之间切换；收起后仅显示菜单图标，鼠标悬停可看到提示。

### 3.2 顶栏

- **左侧**：折叠按钮 + 面包屑导航（如 首页 / 内容管理 / 文章管理，其中带链接的层级可点击跳转）。
- **右侧**：
  - **全屏按钮**：点击进入/退出浏览器全屏；
  - **用户区**：当前用户头像 + 用户名，点击展开下拉菜单：
    - **个人中心**：进入个人资料页；
    - **退出登录**：点击后弹出确认框"确定要退出登录吗？"，确认后退出并返回登录页。

### 3.3 页签栏（多页签）

顶栏与内容区之间为页签栏，方便在多个已打开的功能页之间快速切换：

- 内置固定的"**首页**"标签（`/dashboard`），不可关闭；
- 每次访问一个有标题的页面会自动新增一个标签，重复访问不重复添加；
- 点击标签切换页面；当前页签加粗高亮；
- 标签右侧 **×** 可关闭；关闭当前激活页签后自动跳转到剩余的最后一个标签；
- 页签栏最右侧有"**关闭所有页面**"按钮，点击后仅保留"首页"并回到管理首页。

### 3.4 内容区

展示当前功能页面内容，页面切换带有淡入淡出动画。

### 3.5 通用交互习惯说明

- **列表分页**：绝大多数列表底部有分页条，可选择每页 10 / 20 / 50 / 100 条，支持页码跳转与总数显示；
- **查询 / 重置**：每个列表页的查询区通常提供"查询"与"重置"按钮；
- **删除确认**：删除数据前系统都会弹出二次确认框，请谨慎操作；
- **状态开关**：列表中的"启用/禁用（或上架/下架）"多为开关控件，拨动即保存并即时生效。

## 四、管理首页（工作台）

登录后默认进入"**管理首页**"，集中展示站点运营概况与个人待办。

### 4.1 顶部统计卡片

- **今日访问量**：网站今日累计访问次数；
- **文章总数**：系统中全部文章数量；
- **我的草稿文章**：当前账号下的草稿类文章数量；
- **我的已发布文章**：当前账号已发布（含投稿）文章数量；
- **快捷入口**（5 个图标入口，点击直达）：
  - 用户管理（`/system/users`）
  - 内容发布（`/content/article`）
  - 广告管理（`/content/ad`）
  - 静态化管理（`/content/static`）
  - 系统设置（`/settings`）

### 4.2 访问趋势

- 左侧卡片"**访问趋势**"：面积折线图，展示访问量随时间变化；
- 顶部可选择**年份**（近 5 年）与统计周期 **本周 / 本月 / 全年**；
  - 查看非当年数据时，"本周 / 本月"不可用，系统自动按"全年"统计，切回当年后自动恢复原周期；
- Y 轴单位为"访问次数"。

### 4.3 待处理（个人待审工作台）

- 右侧卡片"**待处理**"，右上角"更多"链接跳转到"内容管理 → 待审核"页；
- 列表中每条显示黄色"审核"标签与"文章《标题》待审核"文案及提交时间；
- **点击某条记录**会进入文章管理并自动打开该文章的"栏目审核流程"弹窗，便于直接审批；
- 无待办时显示"暂无待处理事项"。

### 4.4 发布趋势

- 左侧卡片"**发布趋势**"：面积折线图，展示文章发布数量随时间变化；
- 同样支持年份与 本周/本月/全年 周期切换；Y 轴单位为"文章数量"。

### 4.5 登录日志（最近）

- 右侧卡片"**登录日志**"（无表头小表格），展示最近登录记录：时间、用户名、IP、浏览器 / 系统、状态（成功=绿色 / 失败=红色）；
- 右上角"更多"跳转到"系统配置 → 登录日志"完整列表。

## 五、内容管理

"内容管理"是系统最核心的模块，包含：**待审核、文章管理、广告管理、链接管理、模板管理、栏目管理、分类管理、标签管理、静态化管理**。下文按使用顺序介绍。

> 点击左侧"内容管理"目录展开子菜单即可进入各项。

---

### 5.1 待审核

**功能**：以"审批人"视角展示**当前登录用户待审核的文章队列**（即"待我审核"的待办清单）。

**页面结构**：
- 仅一个"**刷新**"按钮，用于刷新待办；
- 列表标题为"待处理"；每行文章显示为"文章《标题》待审核"；
- 列：序号、文章标题、作者、提交时间、操作（"审核"）。

**操作**：点击行内"**审核**"→ 跳转到文章管理页并自动打开该文章的"栏目审核流程"弹窗，在此完成"通过 / 驳回"（详见 5.2.6 文章审核）。

> 说明：此页展示的是**需要你审批**的文章，只有被配置为流程审批人（部门负责人 / 流程角色成员 / 指定成员）的用户才会看到待办。

---

### 5.2 文章管理

**功能**：门户内容的核心模块，管理**图文、视频、数据、报刊**四类内容，并承载完整的工作流：

> 创作 → 设置投放栏目 → 提交审核 → 逐节点审批 → 发布 / 下线

**适用对象**：
- **作者/编辑**：只能管理自己创作的文章（作者为自己）；
- **管理员**：可额外删除任何人的文章；
- **审批人**：处理待审核事项（经由"待审核"页或首页"待处理"进入）。

#### 5.2.1 查询区（筛选条件）

| 条件 | 说明 |
| --- | --- |
| 文章标题 | 按标题关键字模糊查询 |
| 发布栏目 | 级联选择：模板 → 栏目 → 子栏目（可输入关键字过滤） |
| 文章分类 | 下拉选择分类 |
| 文章标签 | 下拉选择标签 |
| 发布状态 | 全部状态 / 已发布(1) / 草稿(0) / 已下线(2) |
| 审核状态 | 全部状态 / 待审核(0) / 审核中(1) / 已审核(2) |
| 文章类型 | 全部类型 / 图文(1) / 视频(2) / 数据(3) / 报刊(4) |
| 作者 | 按作者姓名/账号查询 |
| 来源 | 按文章来源查询 |

点击 **查询** 执行筛选，点击 **重置** 清空条件。

#### 5.2.2 列表与状态说明

列表主要列：序号、文章标题、作者、来源、发布时间、发布栏目数量、发布状态、审核状态、创建时间、操作。

**文章类型标识**（标题前的小标签）：
- 📄 图文（蓝色）
- 🎬 视频（红色）
- 📊 数据（黄色，列表标题显示为"年月 + 标题"）
- 📰 报刊（绿色，列表标题显示为"期号 + 标题"）

**发布状态**（对应"发布状态"列）：

| 状态值 | 标签 | 说明 |
| --- | --- | --- |
| 0 草稿 | 灰色"草稿" | 新建后尚未发布 |
| 1 已发布 | 绿色"已发布" | 审核通过并已发布（标题变为可点击的蓝色链接，点击可预览） |
| 2 已下线 | 红色"已下线" | 内容已下线不再对外展示 |

**审核状态**（对应"审核状态"列）：

| 状态值 | 标签 | 说明 |
| --- | --- | --- |
| 0 待审核 | 灰色"待审核" | 尚未提交审核 |
| 1 审核中 | 黄色"审核中" | 已提交、正在流转 |
| 2 已审核 | 绿色"已审核" | 全部节点已通过 |

> 当文章已投放栏目（发布栏目数量 > 0）时，**审核状态标签可点击**，点击打开该文章的"栏目审核流程"弹窗查看进度。

#### 5.2.3 列表行操作

每行操作区根据当前用户身份与文章状态动态显示按钮：

| 操作 | 适用/条件 | 说明 |
| --- | --- | --- |
| **编辑** | 作者本人，且非"审核中"；"已审核且未下线"的文章不可编辑 | 审核中会提示"审核中的文章不能编辑"；已审核通过未下线会提示"已审核通过的文章不能编辑"；按文章类型打开对应编辑弹窗 |
| **栏目**（设置投放栏目） | 作者本人，且未处于"已审核" | 设置/修改该文章投放到哪些模板的哪些栏目（见 5.2.7） |
| **提交审核** | 作者本人，草稿、已设栏目、待审核 | 将文章送审（见 5.2.5） |
| **撤回审核** | 作者本人，审核中 | 撤回本次审核请求，回到可编辑状态 |
| **下线** | 已发布 | 将已发布文章下线（下线后状态为"已下线"） |
| **删除** | 作者本人，或管理员 | 永久删除文章 |

> **权限规则小结**：
> - 只有**文章作者**本人可以编辑、设栏目、提交/撤回审核；
> - 已处于"审核中"的文章不能编辑、不能改栏目、可撤回；
> - 已"审核通过"且仍在线的文章不能编辑（需先"下线"才可修改）；
> - 已下线文章可编辑修改后重新送审（点"提交审核"）再次发布。

#### 5.2.4 新增 / 编辑文章

列表左上角/右上角提供新增入口（按类型：图文 / 视频 / 数据 / 报刊）。图文弹窗标题为"新增文章"/"编辑文章"，报刊为独立的"新增报刊"/"编辑报刊"弹窗。

##### （1）图文文章（主要类型）

按分区填写：

**① 基本信息**
- **文章标题**（必填）；
- **所属分类**（多选下拉）；
- **文章标签**（多选下拉）；
- **发布状态**：只读展示；
- **封面图**：上传区（"点击上传封面"，建议尺寸 800×480），上传后显示预览大图，悬停可"删除封面"；
- **文章来源**（选填）；
- **发布时间**（必填，格式 `YYYY-MM-DD HH:mm`，用于定时/展示）。

**② 样式设置**
- **是否置顶**：置顶 / 不置顶；
- **是否加粗**：加粗 / 不加粗；
- **标题颜色**：颜色选择器（支持透明）。

**③ 跳转链接**
- **URL 地址**（选填）：填写后文章保存后将直接跳转到该链接，此时"文章内容与附件无需填写"；若填写，必须以 `http://` 或 `https://` 开头；
- 页面提示：**"URL、文章内容、文章附件至少填写一项"**。

**④ 内容编辑**
- **文章摘要**：多行文本框，最长 500 字（实时显示字数）；
- **文章内容**：**富文本编辑器**，工具栏齐全，支持：
  - 插入图片（≤ 10MB，可多选），**从 Word / 网页复制内容时会自动将图片上传**（智能粘贴，规避防盗链与"本地资源加载"报错）；
  - 其他常见排版（标题、加粗、列表、表格、链接等）。

**⑤ 附件管理**
- **文章附件**：可上传多个附件（最多 10 个），支持 PDF、Word、Excel、PPT、TXT、ZIP、RAR、7Z、MP4、MP3 等常见格式，单个不超过 50MB；同名且同大小的文件会被判重拒绝。

底部按钮：**取消** / **确定**（保存后提示"新增成功 / 修改成功"）。

##### （2）视频文章

在新增时选择"视频"类型（或对视频文章点编辑），弹窗字段与图文类似，但主体为**上传视频**：
- 支持 MP4、MOV 等常见视频格式，单个文件不超过 800MB；
- 上传后可内嵌视频预览；
- 视频以附件形式保存，用于前台视频栏目展示。

##### （3）数据文章

新增时选择"数据"类型：
- 除常规字段外，需**选择年月**（格式"YYYY年MM月"，如 2026年08月，保存为 `YYYY-MM`）；
- 填写**数据内容**（多行文本框，最多 80000 字，必填）；
- 列表标题显示为"年月 + 标题"，用于定期发布统计数据类内容。

##### （4）报刊文章

新增时选择"报刊"类型，弹出独立的"新增报刊"/"编辑报刊"弹窗（非图文富文本表单）：
- **报刊标题**（必填）；
- **期号**：如"2026年第9期"，列表标题显示为"期号 + 标题"；
- **出版年月**（必填，格式"YYYY年MM月"，保存为 `YYYY-MM`，同时作为发布时间）；
- **所属分类 / 文章标签**（多选下拉）；
- **来源**（选填）；
- **封面图**：与图文一致的上传区，建议尺寸 800×480；
- **报刊摘要**：多行文本框，最长 500 字；
- **报刊文件**：上传 PDF 格式报刊文件（≤ 50MB，单个），仅允许 PDF。

报刊文章通过"报刊展示"类栏目（displayType=6）投放展示。

#### 5.2.5 提交审核

1. 文章必须**至少投放一个栏目**（"发布栏目数量 > 0"）才可提交审核；
2. 点击"**提交审核**"，确认框提示"确定要提交文章 X 进行审核吗？"；
3. 若有栏目未绑定审核流程，会追加提示"以下栏目未配置审核流程，将直接通过：……"（即该栏目**免审核直接通过**）；
4. 确认后文章进入"**审核中**"，等待各栏目流程审批人依次处理。

#### 5.2.6 栏目审核流程（审批入口）

**打开方式**：① 点击列表中可点的"审核状态"标签；② 从"待审核"页点"审核"；③ 首页"待处理"点击记录。

弹窗标题"栏目审核流程"，展示该文章每个投放栏目的审核进度卡片：

- 卡片头部：栏目序号 + 栏目名 + 状态标签（已通过=绿 / 已驳回=红 / 审核中=黄 / 显示流程名=蓝 / 未绑定流程=灰）；
- **流程步骤**（步骤条）：自上而下显示各节点名称，节点下方显示当前审批人及操作时间（通过=绿勾，驳回=红叉）；
- 显示"当前节点审批人"类型：部门负责人 / 角色：×× / 指定成员：××；
- 若已通过或驳回，显示"已通过：审批意见"或"已驳回：驳回原因"。

**审批人操作**（只有"当前节点审批人"可见可用，其他人显示"您不是当前节点审批人，无权操作"）：
- **通过当前节点**：先弹出"审核通过原因（可选，≤500 字）"输入框，确定后进入下一节点或全部完成（状态变为"已审核"）；
- **驳回**：必须填写"驳回原因"，驳回后文章回到作者处（作者可修改后重新送审）。

> 审批完成后作者可将文章**发布**；已发布文章也可随时"下线"。

#### 5.2.7 栏目设置（投放栏目）

弹窗标题为"栏目设置 - 文章标题"。用途：选择文章展示在**哪个模板的哪些栏目**，支持跨模板多选。

- **左侧"选择模板"**：列出所有模板及每个模板下符合当前文章类型可投放的栏目数量，点击选中模板；
- **右侧"选择栏目"**：仅展示类型匹配的栏目：
  - 视频文章 → 只能选"视频展示"类栏目；
  - 数据文章 → 只能选"数据展示"类栏目；
  - 报刊文章 → 只能选"报刊展示"类栏目；
  - 图文文章 → 排除上述三类；
  - 栏目卡片标注"需审核"（绑定了审核流程，绿色）或"免审核"（灰色）；子栏目会显示缩进、"子栏目"标签及上级栏目名；
  - 支持"全选"；
- **底部"已选栏目 N 个"**：以蓝色标签展示已选（模板名 / 栏目名），可逐个移除；
- 点击 **确定** 保存投放。

#### 5.2.8 文章预览

点击列表中"已发布"的蓝色标题打开"文章预览"（或系统内预览入口），展示：
- 大标题、作者 / 来源 / 发布时间；
- 封面图（可点击放大）；
- 摘要（灰底"摘要："）；
- 跳转链接（如有，"跳转链接："可点击）；
- 正文（富文本渲染结果）；
- 附件列表（每个附件带图标与名称，可下载）。

### 5.3 栏目管理

**功能**：按类型查看**模板**（Template）及其下的**栏目**（Column，可多级子栏目）结构，并为栏目设置展示类型与审核流程。

> 这是文章投放的基础：文章要先选择栏目，栏目归属于某个模板；栏目在"栏目管理"中按模板维护。

#### 5.3.1 页面类型

"模板列表"卡片头部右侧用一行分段按钮切换页面类型（鼠标悬停可查看类型说明）：
- **首页**：网站门户首页；
- **栏目页**：文章栏目聚合页；
- **详情页**：内容详情展示页；
- **专题页**：专题活动展示页。

#### 5.3.2 模板列表

选中某个模板类型后，中间为该类型的"模板列表"，下方为所选中模板下的"栏目列表"。

**模板列表列**：序号、模板名称、模板描述、状态、创建时间。列表**只显示状态为"启用"的模板**，禁用模板请到"模板管理"中查看或启用。

**操作**：点击某一行 → 下方面目列表直接切换到该模板下的栏目。

> 说明：模板即"页面"（原页面层已合并到模板，栏目直接挂在模板下）。栏目的新增/编辑/删除均在本页完成；模板的编码/访问路径在"模板管理"中维护。

#### 5.3.3 栏目管理

点击模板列表中的某个模板后，下方标题为"{模板名} > 栏目列表"，右侧"**新增栏目**"；无栏目时显示空状态提示。

树形表格（默认全部展开）展示：栏目名称、栏目编码、访问路径、排序、展示方式、栏目审核、状态、创建时间、操作。

**行操作**：
- **子栏目**（新增子栏目）：在选中栏目下增加下级栏目；
- **编辑**、**删除**：删除时有子栏目的会提示"栏目下存在子栏目，确定要一并删除吗？"。

**新增 / 编辑栏目**（弹窗字段）：
- 所属模板（固定为当前所选模板，只读）、栏目名称（必填）、栏目编码（必填）、排序（0–999）；
- 上级栏目（可选，树形下拉，父子不联动）；
- 访问路径（如 `/news/company`）；
- 栏目描述；
- **展示方式**（下拉，默认"列表展示"）——详见下方枚举；
- **栏目审核**（下拉，选择"审核流程"，可选填）：
  - 绑定流程的栏目 = "需审核"栏目，投放到该栏目的文章需走审核；
  - 未绑定流程的栏目 = "免审核"栏目，文章直接通过；
- 状态（启用 / 禁用）。

> **便捷输入**：输入栏目名称时，系统会通过拼音自动生成"栏目编码"与"访问路径"（例如输入"关于我们"自动生成编码 `guanyuwomen`、路径 `/guanyuwomen`），可按需修改。

**栏目展示方式（displayType）枚举**：

| 值 | 展示方式 | 用途 |
| --- | --- | --- |
| 1 | 轮播展示 | 图片轮播 |
| 2 | 列表展示 | 文章列表 |
| 3 | 图片展示 | 图片集 |
| 4 | 广告展示 | 广告位（广告投放） |
| 5 | 友链展示 | 友情链接 |
| 6 | 报刊展示 | 报刊类文章 |
| 7 | 数据展示 | 数据类文章（月度数据） |
| 8 | 视频展示 | 视频类文章 |
| 9 | 其他展示 | 其他自定义 |

> 栏目展示类型会影响可投放的文章类型（见 5.2.7）。

### 5.6 广告管理

**功能**：管理门户图片广告。广告挂载到"模板 → 广告展示栏目"上，可通过状态与起止时间控制投放。

**查询区**：
- 广告名称；
- **广告位置**：先选"模板"，再选该模板下的**广告展示类栏目**（两级联动，未选模板时栏目下拉不可用）；

- 查询 / 重置。

**新增 / 编辑广告**（弹窗字段）：
- 广告名称（必填）；
- 广告位置：模板（必填）→ 栏目（必填，仅可选"广告展示"栏目）；
- 跳转链接（必填）；
- 广告图片：上传（目录 `ad`），预览可放大、可删除；
- 排序（0–999）；
- 状态（上架 / 下架）；
- 开始时间 / 结束时间（选填，格式 `YYYY-MM-DD HH:mm:ss`，用于投放时间窗）。

### 5.7 链接管理（友情链接）

**查询区**：网站名称；友链位置（模板 + 友链展示栏目联动）；状态（启用/禁用）；查询/重置。

**表格列**：序号、网站名称、友链位置、网站链接（可点、新窗口）、Logo（缩略图可放大）、网站描述、排序、作者、状态、创建时间、操作。

**新增 / 编辑友链**（弹窗字段）：
- 网站名称（必填）；
- 友链位置：模板（必填）+ 栏目（必填，仅"友链展示"栏目）；
- 网站链接（必填，必须以 `http://` 或 `https://` 开头，否则提示"链接格式不正确"）；
- Logo：上传（目录 `link`），可预览删除；
- 网站描述、排序、状态（启用/禁用）。

### 5.8 模板管理

**功能**：管理四类页面模板（首页 / 栏目页 / 详情页 / 专题页），支持**源码级模板设计**（编辑 HTML / Vue SFC 源码）与 iframe 实时预览。适用于前端模板开发或站点管理员。

**查询区**：模板名称、模板类型（首页/栏目页/详情页/专题页）、查询/重置。

**表格列**：序号、模板名称、模板类型（标签颜色：首页=绿、栏目页=蓝、详情页=黄、专题页=红）、模板编码、访问路径、描述、状态（开关）、创建时间、操作。

**行操作**：
- **模板设计**：打开宽屏设计弹窗——超大代码编辑区，可编辑模板 HTML / Vue 源码，点击保存；
- **预览模板**：iframe 实时渲染设计效果（优先解析源码中的 `<template>`/`<style>`）；
- **编辑信息**：模板名称、模板编码、模板类型、访问路径、状态、描述；
- **删除**：模板下仍有栏目时会被拦下并提示"该模板下仍有栏目「X」，请先删除或调整该栏目后再删除模板"。

**状态开关（重要）**：**"栏目页"与"详情页"两种类型的模板同时只能启用一个**——启用某个模板时，同类型的其他启用模板会被自动禁用（提示"模板状态已启用，同类型（栏目页）的其他模板已自动禁用"）；首页 / 专题页不受限。在"编辑信息"里改状态启用时同样遵循该规则。

> 模板需与静态化 / 前台页面配套使用。设计模板前建议先了解前台渲染规则。

### 5.9 静态化管理

**功能**：网站**静态化（生成 HTML）运维中心**。用于：
1. 监控外部静态化服务是否在线；
2. 查看各类型页面最后生成时间与今日生成文件数；
3. 发起**批量**静态化任务并跟踪进度；
4. 对**单个页面**重新生成 / 预览 / 删除静态文件；
5. 浏览与清空**静态化日志**。

> 前置：静态化服务地址 / 令牌名 / 输出路径需在"基础配置 → 静态化设置"中正确配置（见 8.1）。

#### 5.9.1 静态化服务监控

- 标题"**静态化服务监控**"；右侧显示服务状态：
  - **运行中**（绿色，带对勾）→ 可发起各类生成；
  - **已停止**（红色，带叉号）→ 批量/单页生成按钮禁用；
- 显示"最后更新时间"；点击"**刷新**"可手动检测。

#### 5.9.2 统计卡片（6 张）

- **今日静态化页面**：今日生成文件数（N 个文件）；
- **全站最后静态化时间**；
- **首页最后静态化时间**；
- **栏目页最后静态化时间**；
- **详情页最后静态化时间**；
- **专题页最后静态化时间**。

#### 5.9.3 批量操作（静态化管理主 Tab）

页面主 Tab：**批量操作**（默认）与**单页操作**；右上角"**静态化日志**"按钮。

**批量生成按钮**（服务离线时禁用）：
- **生成全站**（蓝）：生成全部页面（耗时较长，会先确认"确定要执行生成全站吗？此操作可能需要较长时间。"）；
- **生成首页**（绿）；
- **生成栏目页**（黄）；
- **生成详情页**（红）；
- **生成专题页**（灰）：按输出目录批量重新生成全部专题页。

> **灰度联动**：批量任务会自动带上"首页整体变灰"参数（灰度发布场景，取自 8.1 静态化设置中的开关）。

**任务状态说明**：
- 提交任务后提示"「××」任务已提交，请等待处理结果"；
- 页面**每 3 秒自动轮询**任务状态（提示文字："任务状态自动轮询（每 3 秒），成功/失败/中断将自动通知"），也可点"**刷新任务**"手动刷新；
- 有任务执行中时顶部显示黄色"有任务正在执行中..."（带旋转图标）。

**静态化任务表**列：
- 任务ID、类型（生成全站/首页/栏目页/详情页/专题页）、状态、进度、创建时间、更新时间、操作（刷新）。
- 任务状态：等待执行 / 正在执行（旋转）/ 执行成功 / 执行失败 / 已中断；
- 进度列：阶段文案 + 进度条（成功=100% 绿；失败/中断=红色；执行中无总量=动画进度）+ "已处理 x / y""已生成文件 z"；
- 任务结束时自动弹提示（成功/失败/中断分别提示），并自动刷新页面列表与统计。

#### 5.9.4 单页操作

"单页操作"下有 4 个子页签，可对单个页面重新生成静态文件：

| 页签 | 列表内容 | 行操作 |
| --- | --- | --- |
| 首页 | 首页模板列表（模板名称/访问路径） | 重新生成、预览 |
| 栏目页 | 各栏目（栏目名称/模板） | 重新生成、预览 |
| 详情页 | 各文章（标题/模板/作者/来源） | 重新生成、预览、**删除** |
| 专题页 | 专题页模板列表 | 重新生成、预览、**删除** |

- **重新生成**：离线时提示"静态化服务已停止，无法重新生成页面"；成功后弹出"「名称」生成成功 / 生成时间：…"，并刷新列表与统计；
- **预览**：在新窗口打开该行接口返回的「访问地址」（`url` 字段，由后端统一拼接：**「系统设置 → 基础设置」的「站点地址」** + 该页面的访问路径；未配置站点地址时下发以 `/` 开头的相对地址，由浏览器按当前站点根解析）。`静态化输出路径` 是服务器上的文件输出目录（如 `D:/static`），**不参与预览地址拼接**。未生成过静态文件时预览会 404，请先「重新生成」；该行没有访问路径时预览按钮不可点；
- **删除**（详情页 / 专题页）：删除某文章/专题已生成的静态文件，确认文案"确定要删除文章「标题」(ID: n) 的静态文件吗？删除后需重新生成才能恢复。"（专题页为"确定要删除专题「名称」(ID: n) 的静态文件吗？…"）——删除后需重新生成才能恢复访问。

#### 5.9.5 静态化日志

点击右上角"**静态化日志**"打开时间线弹窗：
- 右上角"**清空日志**"（红色）：确认后清空**全部**静态化日志；
- 每条日志：时间、操作标题、状态标签（成功=绿 / 警告=橙 / 失败=红 / 信息=蓝）、元信息（页面名、路径、耗时、文件大小"N 个文件"、操作人）与明细描述。

## 六、数据统计

### 6.1 内容数据（数据统计首页）

## 七、系统配置

"系统配置"目录包括：**用户管理、部门管理、机构管理、角色管理、菜单管理、流程角色、流程管理、操作日志、登录日志**。其中多数功能面向**管理员**开放，普通内容人员默认看不到相关菜单。

---

### 7.1 用户管理

**功能**：管理系统用户账号（用户名/账号/机构归属/角色/联系方式/状态）。

**查询区**：用户名、用户账号、状态（全部/启用/禁用）、查询/重置。

**列表头部按钮**：**导入用户**（绿色，Excel 批量导入）、**新增用户**（主色）。

**表格列**：序号、用户名、用户账号、所属机构（多机构顿号分隔）、邮箱、手机号、性别、状态（开关）、创建时间、操作（编辑 / 删除）。

**新增 / 编辑用户**（弹窗字段）：
- 用户名（必填）；
- 用户账号（必填；新增时可填，**编辑时不可修改**；重复提示"用户账号已存在"）；
- 所属机构（树形多选，可选多个机构）；
- 邮箱（必填 + 格式校验 + 唯一性校验）；
- 手机号（必填 + 手机号格式校验 + 唯一性校验）；
- 性别（男 / 女 / 未知）；
- 角色（多选，必填）——**只能选择不高于自己权限的角色**；
- 状态（启用 / 禁用）。

**角色分配权限规则**（重要）：
- 角色 ID 越小权限越高；当前用户只能为他人分配**权限不高于自己**的角色；
- 若试图分配更高角色，会被拦截并提示"不能设置高于当前登录用户最高角色的角色"。

**其他操作**：
- **状态开关**：启用/禁用用户（内置管理员账号 `id=1` 不可禁用、不可删除）；
- **编辑 / 查看**：内置管理员账号打开为只读"查看用户"；
- **删除**：二次确认后删除（内置管理员不可删除）；
- **导入用户**：仅支持 `.xlsx / .xls`，第一行为标题：**姓名、登陆账号、邮箱、手机号**；导入完成后提示"导入完成，成功 X 条，失败 Y 条"。

> 说明：用户密码由用户本人在"个人中心"自行修改；系统暂无管理员"重置密码"按钮。

---

### 7.2 部门管理

**功能**：管理**机构（组织）下的部门树**（内设部门），支持给部门批量"选人"与人员查看。

**查询区**：部门名称、状态、查询/重置（对树进行过滤剪枝，无分页）。

**列表头部**：**导入部门**（绿）、**新增部门**（主色）。

**树形表格列**：部门名称、部门编码、所属机构、负责人、人员数量、排序、状态、创建时间、操作。

**行操作**：
- **子部门**：在当前部门下新增下级部门；
- **选人**：为该部门分配成员（见下）；
- **人员查看**：只读查看当前部门成员（可搜索）；
- **编辑**、**删除**（有子部门时需先删除子部门）。

**新增 / 编辑部门**（弹窗字段）：
- 所属机构（必填，机构树选择）——部门必须挂在某机构下；
- 上级部门（可选）；
- 部门名称（必填）、部门编码（必填）；
- **负责人**（下拉，可搜索）：**必须先选所属机构**；候选**仅限该机构的成员**；选中后自动回填负责人姓名；
- 显示排序（0+，必填）；
- 状态（启用 / 禁用）、描述。

**部门选人弹窗**：支持搜索（用户姓名/账号）；列表带多选，**仅能选择该机构成员**；已在本部门的人默认勾选；点确定后全量保存（即最终勾选集合覆盖原成员），提示"人员分配成功"。

**导入部门**：仅支持 `.xlsx / .xls`，第一行为标题：**上级部门ID（没有就是0）、部门名称、部门编码、机构名称**。

> 约束：部门负责人必须属于该部门所属的机构。

---

### 7.3 机构管理

**功能**：管理**顶级组织单元（机构 / 分支机构）树**——含机构类型、层级、分类、区域、管理员等信息，并可在机构下直接新建"内设机构（部门）"。

**查询区**：机构名称、机构类型（机构 / 分支机构）、状态、查询/重置。

**列表头部**：**新增机构**。

**树形表格列**：机构名称、机构编码、机构类型（标签：机构=红、分支机构=橙）、层级、**部门层级**（内嵌展示该机构下所有部门树）、机构分类、所属区域、管理员、人员数量、排序、状态、创建时间、操作。

**行操作**：
- **内设机构**：在选中的机构下新增"部门"（走部门创建流程，机构已自动带入）；
- **人员查看**：只读查看机构成员（可搜索）；
- **编辑**、**删除**（有子机构时需先删除子机构）。

**新增 / 编辑机构**（弹窗字段）：
- 上级机构（可选；若系统已存在顶级机构则必须选择上级，系统会提示"已有顶级机构，请选择上级机构"——**仅允许存在一个顶级机构**）；
- 机构类型（机构=1 / 分支机构=2，必填）；
- 机构名称（必填）、机构编码（必填）；
- 机构层级（1–10，必填；选择上级后自动为上级层级 +1）；
- 机构分类（如：职能/业务/区域）、所属区域；
- **管理员**（下拉可搜索，**候选仅限管理员（角色 ID=1）的用户**；原「普通管理员」角色已下线）；
- 省份 / 城市、详细地址；
- 显示排序（必填）、状态（启用 / 禁用）、描述。

> 说明：机构的人员归属通过用户编辑页的"所属机构"或部门"选人"间接维护；机构页仅提供只读"人员查看"。

---

### 7.4 角色管理

**功能**：维护系统角色并为其**分配权限（菜单树）**。

**内置受保护角色**（不可编辑、不可删除）：ID 1 / 3 / 4，即管理员 / 内容审核 / 内容作者（原 ID 2「普通管理员」已下线移除，如历史库中仍有该角色，按普通角色处理）。

**查询区**：角色名称、查询/重置。

**列表头部**：**新增角色**。

**表格列**：序号、角色名称、角色编码、描述、状态（启用=绿 / 禁用=灰标签）、创建时间、操作（**权限/查看**、编辑、删除）。

**新增 / 编辑角色**（弹窗字段）：角色名称（必填）、角色编码（必填）、描述、状态（启用/禁用）。

**分配权限（核心）**：
- 点击行内"**权限**"打开"分配权限"弹窗（树形勾选，节点为系统菜单，即"权限点 = 菜单项"）；
- 勾选后仅保存**叶子节点**权限；保存提示"权限分配成功"；
- 管理员（id=1）与权限高于自己的角色为只读"**查看权限**"，不可修改。

> 权限即菜单：分配权限后，对应角色的用户登录时左侧菜单会自动按该权限树的叶子节点生成。

---

### 7.5 菜单管理

**功能**：维护后台**左侧导航菜单树**（目录 / 菜单两级），配置名称、路由路径、组件、图标、排序、显示状态。**仅管理员可操作**，其他角色只能查看。

**树形表格列**：菜单名称（带图标）、路由路径、组件路径、排序、类型（目录=蓝 / 菜单=绿标签）、状态（显示=绿 / 隐藏=灰标签）、操作。

**行操作**（仅管理员）：**子菜单**、**编辑**、**删除**。

**新增 / 编辑菜单**（弹窗字段）：
- 上级菜单（树形选择，含"顶级菜单"，父子不联动）；
- 菜单类型（目录 / 菜单）：目录用于分组，菜单需绑定组件页面；
- 菜单名称（必填）、路由路径（必填）；
- 组件路径（仅"菜单"类型显示，对应前端页面）；
- 菜单图标：点击放大镜打开"**选择图标**"弹窗（可搜索图标名称），支持清空；
- 显示排序（≥0，必填）、显示状态（显示 / 隐藏）。

> 注意：菜单路由/组件路径需与前端视图对应，错误配置会导致菜单点击无页面或跳转 404，请由熟悉系统的管理员操作。

---

### 7.6 流程角色（审批人角色）

**功能**：为审核流程定义独立于系统角色的"流程角色"（例如"审核组/复审组"），并配置其成员；审核流程节点可引用这些流程角色作为审批人。

**查询区**：角色名称、查询/重置。

**列表头部**：**新增流程角色**。

**表格列**：序号、角色名称、角色编码、描述、状态（启用/禁用标签）、创建时间、操作（**成员**、编辑、删除）。

**设置成员**：点击"成员"打开弹窗——顶部横幅显示角色名与"已选 N 人"，主体为**穿梭框**：
- 左"可选成员"、右"已选成员"；支持按用户名/账号搜索；
- 成员池为全部启用状态用户；
- 确定后全量保存（覆盖），提示"成员设置成功"。

---

### 7.7 流程管理（审核流程配置）

**功能**：定义文章的**审批流程**——每个流程由"基本信息 + 自上而下的线性审批节点链"组成。

> 流程能力说明：审批流为**顺序线性节点**，一个流程可配置多个节点，文章按节点顺序逐级审批；不支持分支 / 并行 / 会签。

**查询区**：流程名称、查询/重置。

**列表头部**：**新增流程**。

**表格列**：序号、流程名称、状态（启用/禁用标签）、节点数、创建时间、操作（**设计流程**、编辑、删除）。

**新增 / 编辑流程**（弹窗字段）：流程名称（必填）、状态（启用=1/禁用=0）、流程说明。

**设计流程**（弹窗，核心）：
- 顶部显示流程名 + "**添加节点**"；
- 节点按顺序垂直排列，节点间用向下箭头连接；
- 每个节点配置：
  - **节点名称**；
  - **审批人类型**：指定成员（user）/ 部门负责人（dept_head）/ 角色（role）；
    - ⚠️ **只有第 1 个节点可选"部门负责人"**，从第 2 个节点起仅能选择"指定成员"或"角色"；
  - 依据类型选择对象：
    - 指定成员 → 下拉选择"选择成员"；
    - 角色 → 下拉选择"选择流程角色"；
    - 部门负责人 → 固定显示（灰色只读）；
  - 节点操作：**上移 / 下移 / 删除**（首节点不能上移、末节点不能下移）；
- 保存校验：节点名不能为空、指定成员/角色必须选择对象、第 2 节点起不能设置部门负责人；通过后提示"流程设计保存成功"。

> 流程创建并**启用**后，即可在"栏目管理"中为栏目绑定该流程（见 5.3.3）。

---

### 7.8 操作日志

**功能**：审计后台的各类管理操作（增、删、改、查、登录等），供管理员审计。

**查询区**：操作人、操作类型（新增 CREATE / 修改 UPDATE / 删除 DELETE / 查询 READ / 登录 LOGIN）、操作时间（日期范围）、查询/重置。

**列表头部**：**清空日志**（红色）。

**表格列**：序号、操作人、操作类型（标签：新增=绿 / 修改=黄 / 删除=红 / 查询=灰 / 登录=蓝）、操作模块、操作描述、IP 地址、耗时（>1000ms 显示红色）、操作时间、操作（**详情**）。

**查看详情**：弹窗展示操作人、类型、模块、描述、请求方法、请求路径、请求参数（等宽样式）、IP、User-Agent、操作时间。

**清空日志（重要策略）**：操作日志**只清空半年前的日志**，保留最近半年。确认框会提示"仅能清空（半年前日期）之前的日志，系统将保留（日期）至今的最近半年日志。确定继续吗？此操作不可恢复！"。

---

### 7.9 登录日志

**功能**：记录每次登录尝试（成功/失败 + 终端信息），只读审计页。

**查询区**：用户名、登录状态（成功/失败）、登录时间（日期范围）、查询/重置。

**列表头部**：**清空日志**（红色）。

**表格列**：序号、用户名、IP 地址、浏览器、操作系统、设备、状态（成功=绿 / 失败=红标签）、登录时间。

> 与操作日志不同，登录日志**清空为全部清空**（确认提示"确定要清空所有登录日志吗？此操作不可恢复！"）。

## 八、基础配置

"基础配置"目录包含：**静态化设置**与**系统设置**。这两项属全局参数，建议由系统管理员维护。

---

### 8.1 静态化设置

**功能**：配置外部**静态化程序**的连接参数与各类型页面的固定生成时间（只做参数保存；真正的生成与监控在"内容管理 → 静态化管理"）。

**配置字段**：
1. **静态化输出路径**：如 `D:/static`——静态文件输出目录（详情页 / 专题页删除静态文件时也会用到该路径）；
2. **静态化程序访问地址**：如 `127.0.0.1:8889`；
3. **静态化程序访问令牌名**：如 `CAAM_TOKEN`（令牌名 = 程序读取的环境变量名，需与服务端约定一致）；
4. **首页整体变灰**：开关（开启后，批量生成全站/首页时携带"变灰"灰度参数，用于哀悼日等场景）；
5. **设置首页固定静态化时间**：开关 + 时间选择（HH:mm），用于定时自动生成首页；
6. **设置栏目页固定静态化时间**：同上；
7. **设置专题页固定静态化时间**：同上；
8. **设置详情页固定静态化时间**：同上。

点击 **保存设置** 一次性保存全部字段（成功后提示"保存成功"）。

> 说明：上述"固定静态化时间"仅作为全局配置保存，**定时调度由后端/静态化程序执行**，前端不负责触发。

---

### 8.2 系统设置

**功能**：维护站点基础信息、安全策略与邮件（SMTP）配置。页面分为三个页签。

> ⚠️ **重要**：本页任何一项点"**保存设置**"成功后，系统都会提示"保存成功，请重新登录"并**自动退出登录**回到登录页（安全设置变更会同步到本地），属正常现象。

#### （1）基础设置
- **系统名称**：显示在浏览器标题/登录页的系统名；
- **访问域名**：如 `https://www.miic.com.cn`；
- **系统 Logo**：点击上传（仅图片、≤2MB），上传后 120×120 预览；Logo 会作为浏览器 favicon 显示；
- **备案信息**：如 ICP 备案号（显示在登录页底部）；
- **版权信息**：如"××版权所有"（显示在登录页底部）；
- **机构名称**、**机构编码**。

#### （2）安全设置
- **登录失败锁定**：开关（启用后连续失败达到上限将锁定账号）；
- **最大失败次数**：3–10 次；
- **锁定时间(分钟)**：5–60 分钟；
- **密码最小长度**：6–20 位（默认 8，个人中心改密时遵循此规则）；
- **Token 有效期(小时)**：1–72 小时（控制登录态有效期）。

#### （3）邮件设置
- **SMTP 服务器**（如 `smtp.example.com`）、**SMTP 端口**（如 587）；
- **发件人邮箱**、**发件人名称**；
- **邮箱密码**（或授权码，密码框可切换明文）；
- **启用 SSL**：开关（默认开启）；
- 按钮：**测试连接**、**保存设置**。

> 说明：当前版本"测试连接"仅为演示性操作（点击提示"邮件连接测试成功"），并不真正发送测试邮件；邮件功能主要用于系统向用户发送通知类邮件（如适用）。

## 十、常见问题与注意事项

### 10.1 常见操作流程速查

**流程 A：发布一篇图文文章（走审核）**
1. 内容管理 → 文章管理 → 新增（图文）；
2. 填写标题、分类/标签、封面、发布时间、正文（可上传图片/附件），点确定保存为草稿；
3. 对草稿点"栏目"，选择要投放的模板与栏目，确定；
4. 点"提交审核"（栏目若免审核则直接通过）；
5. 审批人在"待审核"或首页"待处理"打开审核弹窗，逐节点"通过当前节点"；
6. 全部通过后，作者点"发布"（草稿→已发布）；需要时可"下线"。

**流程 B：修改已发布文章**
先"下线"→ 点"编辑"修改 → 重新送审（点"提交审核"）→ 通过后再次发布。

**流程 C：审核一篇文章**
首页"待处理"→ 点记录 → 在"栏目审核流程"中：通过填意见（可选）或驳回填原因 → 完成。

**流程 D：让网站内容更新到线上（静态化）**
内容发布/修改后，进入"静态化管理"：可对单个详情/栏目点"重新生成"，或批量"生成全站/首页/栏目页/详情页"（生成成功后前台刷新即可看到）。

### 10.2 常见问题

- **登录失败或账号锁定？** 连续输错密码达到"安全设置"中的次数将被锁定一段时间，请稍后再试或联系管理员。
- **看不到某些菜单？** 菜单按角色权限显示，请联系管理员在"角色管理 → 权限"中分配。
- **保存系统设置后为何被退出？** 属正常安全机制，请重新登录。
- **审核中的文章无法编辑/删除？** 审核中锁定编辑，请先"撤回审核"再操作。
- **为何详情页"删除"后前台打不开？** 删除的是已生成的静态文件，需在静态化管理中对该详情页"重新生成"恢复。
- **"生成专题页"为何提示未实现？** 当前版本专题页静态化尚未接入，属预期提示。

### 10.3 注意事项

1. **数据删除不可恢复**（文章、栏目、模板、角色、菜单、日志等删除均不可逆，操作前请二次确认）；
2. **日志清空策略不同**：操作日志保留最近半年；登录日志与静态化日志为全部清空；
3. 删除被引用的对象前系统会提示（模板下有栏目、栏目下有子栏目等），请评估影响；
4. 上传大小限制：封面/图片 ≤ 2MB（系统 Logo）~ 10MB（富文本）不等、附件单文件 ≤ 50MB（视频 ≤ 800MB），请注意素材规格；
5. 首次登录请立即修改初始密码；"栏目页/详情页"两种类型的模板同一时间仅允许启用一个；
6. 静态化需先保证外部静态化服务在线，并在"静态化设置"中正确配置地址/令牌/输出路径。
