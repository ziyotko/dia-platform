## 一、系统概述

项目申报评审系统是一个覆盖「**项目申报 → 材料上传 → 在线初审 → 专家评审 → 结果公示 → 证书颁发**」全流程的 Web 系统，由同一站点下的**两个入口**组成：

| 入口 | 使用人 | 登录地址 | 主要能力 |
| --- | --- | --- | --- |
| **申报人端** | 申报人（注册用户） | `/business_application/login`（首页「申报入口」） | 浏览可申报项目、填写并提交申报、上传材料、查看进度/结果、下载证书、接收通知 |
| **管理端** | 管理人 / 评审人 / 超级管理员 | `/business_application/admin/login`（首页「管理后台」） | 维护类别/批次/专家库、在线初审、分配评审、专家打分、确定结果、结果公示、证书管理、申报人与通知管理 |

> **两套账号互不通用**：申报人账号与管理端账号是两套独立的账号体系。管理端内置账号 `admin` 在申报人登录页填写必然提示「用户名或密码错误」，属预期行为。

**支撑模块**

- **专家库**：维护评审专家档案（专业领域、职称、单位、简介），新增专家时**自动创建评审人登录账号**，账号与专家档案一一对应。
- **站内通知**：流程每推进一步自动给申报人发站内信；管理端也可手工群发或定向通知。
- **系统日志**：管理端所有写操作留痕，可按模块与关键字检索。

### 1.1 访问方式

在浏览器中打开部署地址。系统通常部署于 Nginx 站点子路径下（当前口径为 `/business_application/`），**实际地址以管理员提供的为准**。

打开站点后首先看到**公共首页**：顶部为站点标题「项目申报评审系统」与两个入口链接——「**申报入口**」（去申报人登录页）、「**管理后台**」（去管理端登录页），页脚显示版权信息。

### 1.2 浏览器要求

建议使用主流现代浏览器（Chrome / Edge / Firefox 等）的最新版本，并开启 JavaScript，以获得完整功能与最佳体验。会话有效期默认 24 小时（由后端 `jwt.expire_hours` 决定），过期后需重新登录。

## 二、账号与登录

### 2.1 申报人注册

入口：申报人登录页底部「还没有账号？立即注册」，或首页「申报入口」→ 注册。

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 用户名 | 必填 | 登录账号，全局唯一 |
| 真实姓名 | 必填 | |
| 密码 | 必填 | |
| 确认密码 | 必填 | 与密码一致，否则提示「两次密码不一致」 |
| 所在单位 | 选填 | |
| 联系电话 | 选填 | |
| 电子邮箱 | 选填 | |
| 验证码 | 必填 | 5 位（数字 + 大写字母，不区分大小写），点击图片可刷新；错一次即作废需重新获取 |

点击「注 册」后提示「注册成功，请登录」并跳回登录页。若用户名已被占用，会提示「用户名已存在」。

> 注册与登录同为公开接口，已加验证码与按 IP 限流（10 次/分钟）：验证码错误或漏填会提示「验证码错误」/「请填写完整信息（含验证码）」，被限流会提示「请求过于频繁，请稍后再试」。

> 注册成功后默认状态为「正常」，可直接登录；后续资料（身份证号、职务等）可在「个人资料」中补充。

### 2.2 申报人登录

1. 打开申报人登录页，依次输入**用户名**、**密码**、**验证码**（5 位，数字 + 大写字母，不区分大小写）。
2. 验证码图片位于密码框下方，**点击图片可刷新**；图片未加载时显示灰字「点击刷新」，点击即可重新获取。
3. 点击「登 录」（或直接按回车）进入「申报中心」。

失败提示与原因：

| 提示 | 原因 |
| --- | --- |
| `验证码错误` | 验证码输错或已过期（验证码 5 分钟内有效，**校验一次即作废**，需点击图片刷新） |
| `用户名或密码错误` | 账号不存在或密码错误 |
| `账号已被禁用` | 账号被管理员停用，请联系管理方 |

验证码接口有按 IP 的限流（30 次/分钟），频繁刷新会提示「请求过于频繁，请稍后再试」。

### 2.3 管理端登录

入口：首页右上角「管理后台」，或直接访问 `/business_application/admin/login`。

字段与操作同申报人登录，页面底部有提示「默认账号：admin / manager / reviewer」。登录成功后进入「管理看板」，并按账号角色加载左侧菜单。

### 2.4 内置账号（初始）

| 用户名 | 姓名 | 角色 | 初始密码 |
| --- | --- | --- | --- |
| `admin` | 超级管理员 | 超级管理员 | `1qaz@WSX` |
| `manager` | 项目管理员 | 管理人 | `1qaz@WSX` |
| `reviewer` | 评审专家 | 评审人 | `1qaz@WSX` |

> 首次部署后请立即登录并修改密码。首次登录后系统**不会**再重置这些密码。

### 2.5 退出登录

- 申报人端：右上角姓名 → 「退出登录」。
- 管理端：右上角姓名 → 「退出登录」。

退出后回到对应登录页，需要重新输入账号密码与验证码。

## 三、申报人端

### 3.1 主界面与通用操作

登录后进入 `/member/*` 布局：

- **左侧导航栏**：申报中心、可申报项目、我的申报、结果公示、我的证书、通知中心（带未读红点，最多显示 `99+`）、个人资料。左上角标题「申报系统」，点击返回「申报中心」。
- **顶栏**：左侧折叠按钮（收起侧边栏）；右侧显示姓名（未设置时显示「申报人」），下拉含「个人资料」「退出登录」。
- **内容区**：浅灰底、白色卡片。

**通用交互约定**

| 项目 | 约定 |
| --- | --- |
| 列表分页 | 每页固定 **10 条**，仅提供「总数 / 上一页 / 页码 / 下一页」，无每页条数与跳页控件 |
| 筛选查询 | 输入框按回车即查询；清空图标点击后自动查询；下拉筛选改变后立即查询 |
| 时间显示 | 统一格式 `YYYY-MM-DD HH:mm`，无值显示 `-` |
| 错误提示 | 由系统统一弹出（右上角红色提示），页面不再重复弹窗 |
| 会话过期 | 自动清理登录状态并跳转登录页 |

### 3.2 申报中心

**统计卡片（4 张）**

| 卡片 | 含义 |
| --- | --- |
| 我的申报 | 我名下的全部申报（含草稿）数量 |
| 已提交 | 已提交过的申报数量（草稿以外的记录） |
| 通过立项 | 状态为「已通过 / 已公示 / 已发证」的申报数量 |
| 获得证书 | 我持有的证书数量 |

**快捷入口**：浏览可申报项目 / 我的申报 / 结果公示 / 我的证书。

> 顶栏「通知中心」有未读消息时会显示红点数字，系统每 60 秒自动刷新一次，切换页面或从其他标签页切回时也会立即刷新。

### 3.3 可申报项目

用于浏览当前已发布（非草稿）的申报批次，并进入申报。

**筛选**：输入框「搜索项目名称」+「查询」。

**列表列**

| 列 | 说明 |
| --- | --- |
| 项目名称 | 批次名称 |
| 项目类别 | 批次锁定的项目类别 |
| 申报时间 | `开始 ~ 截止` |
| 状态 | 草稿 / 申报中 / 评审中 / 已结束（**草稿批次不会出现在此处**） |
| 操作 | 申报要求 / 立即申报 |

**行操作**

- **「申报要求」**：打开弹窗，显示项目类别、当前状态、申报时间，以及「申报要求」与「批次说明」两段正文（保留换行；为空显示「无」）。批次已不接受申报时，弹窗顶部有灰色提示条「该批次当前{状态}，已不接受新的申报」。
- **「立即申报」**：仅在批次状态为「**申报中**」且当前时间落在申报窗口内时可点击（否则按钮置灰）。点击后进入「项目申报」表单，并自动带出该批次与锁定的项目类别。

### 3.4 我的申报

**筛选**：输入框「搜索项目名称」+ 状态下拉「全部状态」+「查询」；右上角「新建申报」。

**列表列**：项目名称 / 申报批次 / 状态 / 评审平均分 / 提交时间 / 操作。

- **评审平均分**：尚无专家评分时显示 `-`（不显示 0 分）。

**行操作（按状态显示）**

| 按钮 | 显示条件 | 行为 |
| --- | --- | --- |
| 查看 | 始终 | 进入申报详情 |
| 修改 | 状态为「草稿」或「初审驳回」 | 进入申报详情（可编辑态） |
| 撤回 | 状态为「待初审」 | 二次确认后撤回，提示「已撤回，可继续修改」 |
| 删除 | 状态为「草稿」或「初审驳回」 | 确认「确认删除该申报？」后删除（同时删除已上传的材料与文件） |

### 3.5 项目申报（新建）

从「我的申报 → 新建申报」或「可申报项目 → 立即申报」进入。

| 字段 | 是否必填 | 说明 |
| --- | --- | --- |
| 申报批次 | 必填 | 只列出**当前仍在申报期内**的批次 |
| 项目类别 | 不可选（只读） | 由所选批次决定，提示「项目类别由申报批次决定，不可修改」 |
| 项目名称 | 必填 | 最多 100 字符，带字数统计 |
| 项目简介 | 选填 | 建议 200 字以内 |
| 申报内容 | 选填 | 项目背景、目标、实施方案、预期成果等 |

点击「保存草稿」后提示「草稿已保存，请上传材料后提交」，并跳转到该申报的**详情页**继续上传材料、提交申报。

> 若所选批次未设置项目类别，会提示「该批次未设置项目类别，请联系管理员」。

### 3.6 申报详情（申报人端）

详情页是申报的**主操作页**，从上到下依次为：标题与状态标签 → 进度条 → 基本信息 → 申报材料 → 初审意见 → 专家评审 → 评审结果 → 底部操作区。

**（1）进度条（6 步）**

`提交申报 → 在线初审 → 专家评审 → 评审结果 → 结果公示 → 颁发证书`

进度按状态自动定位；被驳回时停留在「在线初审」步。

**（2）基本信息**

- 只读态显示：申报批次、项目类别、项目名称、提交时间、项目简介、申报内容。
- 状态为「草稿」或「初审驳回」时自动切换为**可编辑表单**（项目类别只读，其余可改），点击「保存信息」保存。

**（3）申报材料**

| 列 | 说明 |
| --- | --- |
| 材料名称 | 原文件名 |
| 类型 | 扩展名 |
| 大小 | 以 KB 显示 |
| 操作 | 下载 / 删除（删除仅在可编辑态出现） |

可编辑态下有「上传材料」按钮。**上传限制**：

- 允许类型：`pdf`、`doc`、`docx`、`xls`、`xlsx`、`ppt`、`pptx`、`txt`、`zip`、`rar`、`jpg`、`jpeg`、`png`、`gif`；
- 单文件不超过 **50MB**，超出提示「文件大小不能超过 50MB」，类型不符提示「不支持的文件类型」；
- 单份申报最多 **20 份**材料，超出提示「材料数量不能超过 20 份」。

> 提交申报前**必须至少上传一份材料**（未上传时提交会被拦截并提示「请先上传申报材料」）。
> 材料列表是整体保存的：删除某条材料后，对应文件也会被一并删除。

**（4）初审意见**：仅初审后出现。显示管理人填写的意见；被驳回时为红色提示，并附「初审未通过，请修改申报信息或材料后重新提交（需在申报截止前）。」

**（5）专家评审**：分配评审人后出现。列为 评审人 / 状态（待评审、已评分）/ 评分 / 评审意见；已有人评分时底部显示「综合平均分：{分数}（{已评分数}/{总分配数} 位专家已评分）」，否则显示「暂无专家评分」。

**（6）评审结果**：管理人确定结果后出现，显示通过 / 不通过及意见；已公示的还会显示「公示时间」。

**（7）底部操作区（按状态互斥出现）**

| 状态 | 可执行操作 |
| --- | --- |
| 草稿 | 大按钮「提交申报」 |
| 初审驳回 | 大按钮「修改后重新提交」 |
| 待初审 | 「撤回申报」+ 提示「撤回后申报将回到草稿状态，可继续修改后重新提交」 |
| 其他状态 | 只读，无操作按钮 |

**提交校验**：批次已截止时提示「该批次已截止申报」；无材料时提示「请先上传申报材料」。
**撤回**：详情页撤回不弹确认框，成功后提示「已撤回，可继续修改」。

### 3.7 结果公示

页面分两个标签页，展示同一批数据的两种形式：

**（1）公示公告**：管理端发布的自由文本公告。

| 列 | 说明 |
| --- | --- |
| 公示标题 | |
| 所属批次 | |
| 发布时间 | |
| 操作 | 「查看」打开弹窗阅读全文（保留换行） |

**（2）评审结果**：逐条结果公示，只显示已公示（有公示时间）的申报。

> 该列表对全体申报人可见，因此只返回项目名称、申报人姓名、所属批次、评审结果与公示时间；申报人的联系方式、身份证号等身份信息不会下发。

| 列 | 说明 |
| --- | --- |
| 项目名称 | |
| 申报人 | |
| 所属批次 | |
| 评审结果 | 通过（绿色）/ 未通过（红色） |
| 公示时间 | |

> 判定口径：状态为「已公示」或「已发证」显示「通过」，其余显示「未通过」。

### 3.8 我的证书

列表（不分页）显示：证书编号 / 证书名称 / 持有人 / 所属项目 / 颁发时间 / 状态 / 操作。

- 状态：未颁发（草稿，一般不会出现在申报人端）/ 已颁发 / 已作废。
- 「下载证书」按钮仅在该证书已上传文件时显示，点击在新标签页打开文件。
- **已作废的证书不会下发给申报人**（列表不可见）。

### 3.9 通知中心

由流程自动产生的站内消息：申报已提交、初审通过/未通过、评审已完成、评审结果（通过/未通过）、结果已公示、证书已颁发、证书已作废、评审结果已撤回等。

- 顶部左侧：未读数量标签（如「3 条未读」），全部已读时显示「全部已读」。
- 顶部右侧：「全部已读」按钮（无未读时置灰），成功后提示「已将 N 条通知标记为已读」。
- 列表列：标题 / 内容（全文展示）/ 时间 / 状态（已读、未读）/ 操作（「标记已读」，仅未读行显示）。

### 3.10 个人资料

**（1）个人资料**：用户名（不可修改）、真实姓名、联系电话、电子邮箱、身份证号、所在单位、职务 → 「保存资料」。

**（2）修改密码**：原密码、新密码 → 「修改密码」，成功后提示「密码修改成功」。

## 四、管理端

### 4.1 主界面与通用操作

- **左侧导航栏**：标题「评审管理后台」（折叠时显示「评」），点击返回「管理看板」。
- **顶栏**：折叠按钮；右侧姓名下拉（「个人资料」「退出登录」）。
- **菜单按角色加载**：

| 角色 | 可见菜单 |
| --- | --- |
| 超级管理员 / 管理人 | 管理看板、类别管理、专家库、批次管理、申报管理、评审管理、评审任务、结果公示、证书管理、通知管理、申报人管理、账号管理（仅超级管理员）、系统日志、个人资料 |
| 评审人 | 管理看板、我的评审、个人资料 |

**通用交互约定**

| 项目 | 约定 |
| --- | --- |
| 分页 | 每页固定 **10 条**（总数 / 上一页 / 页码 / 下一页） |
| 删除类操作 | 弹出确认框（标题「提示」），按钮为「确定 / 取消」 |
| 不可逆操作 | 先弹确认或输入框（如作废证书需填原因） |
| 状态类按钮 | 多数为「置灰不可点」而非隐藏；仅批次的「发布」「开始评审」「结束」与部分公示按钮按状态隐藏 |
| 时间显示 | 统一 `YYYY-MM-DD HH:mm`，无值显示 `-` |
| 平均分 | 无有效评分时显示 `-` |
| 上传限制 | 单文件 ≤ 50MB、扩展名白名单同申报人端；上传接口需具备「初审」或「证书管理」权限（评审人无上传入口，直接调用会被拒绝） |

### 4.2 管理看板

一次登录只显示**一套**卡片，取决于当前账号角色：

**管理人 / 超级管理员（8 张）**：申报批次、申报总数、待初审、评审中、通过立项、申报人、颁发证书、开放批次。

**评审人（2 张）**：待评审任务、已完成评审。

> 卡片口径：「待初审」= 状态为待初审的申报数；「评审中」= 待评审 + 评审完成；「通过立项」= 已通过 + 已公示 + 已发证；「开放批次」= 状态为申报中的批次。

### 4.3 类别管理

维护「项目类别」，批次与申报都挂在类别上。

- 筛选：「搜索名称」（前端即时过滤）。
- 列表列：ID / 类别名称 / 说明 / 排序 / 操作。
- 「新增类别」/ 行内「编辑」：弹窗标题「新增类别」或「编辑类别」，字段 名称、说明、排序（不小于 0）→「保存」。
- 行内「删除」：确认「确认删除该类别？」；**该类别下存在申报批次时会拒绝删除**。

### 4.4 专家库

维护评审专家，**新增专家会自动创建对应的评审人登录账号**。

- 筛选：「搜索姓名/账号/领域/单位」+ 状态下拉（全部状态、启用、停用）+「查询」。
- 列表列：ID / 姓名 / 登录账号 / 专业领域 / 职称 / 单位 / 电话 / 评审任务（如 `3/5`，表示已评分/分配总数）/ 状态 / 操作。

| 操作 | 说明 |
| --- | --- |
| 新增专家 | 弹窗字段：姓名、登录账号、登录密码（「请输入初始密码」）、专业领域（如：人工智能、生物医药、新材料）、职称（如：教授、研究员、高级工程师）、单位、电话、邮箱、专家简介 |
| 编辑 | 登录账号不可修改；登录密码留空表示不修改（其它字段会同步更新登录账号的姓名/电话/邮箱） |
| 停用 / 启用 | 按钮文字随状态变化，**无确认框**，提示「状态已更新」；专家档案与登录账号状态同步 |
| 删除 | 确认「确认删除专家「姓名」？」；**该专家存在评审任务时拒绝删除**；删除会同时删除其登录账号与专家档案 |

> 评审人登录账号请统一从「专家库」新增——「账号管理」新增评审人会被拒绝（提示「评审人账号请通过「专家库」新增」）。

### 4.5 批次管理

批次 = 一轮申报（申报通知 + 申报窗口 + 评审截止）。

- 筛选：「搜索批次名称」+ 状态下拉（全部状态、草稿、申报中、评审中、已结束）+「查询」。
- 列表列：批次名称 / 类别 / 申报起止 / 评审截止 / 状态 / 操作。

**新增 / 编辑弹窗**（标题「新增批次」或「编辑批次」）

| 字段 | 说明 |
| --- | --- |
| 批次名称 | 必填 |
| 项目类别 | 必填；**批次发布后不可再改**（置灰） |
| 申报开始 / 申报截止 | **批次发布后不可再改**（置灰），需填写完整才能发布 |
| 评审截止 | 始终可改；留空表示评审不设截止时间 |
| 申报要求 | 申报人可在「申报要求」弹窗中看到该内容 |
| 批次说明 | 同上 |

**行操作**

| 按钮 | 显示条件 | 说明 |
| --- | --- | --- |
| 编辑 | 始终 | 保存前校验：批次名称必填；未锁定时必须选择项目类别 |
| 发布 | 状态为「草稿」 | 需已填写申报开始与截止时间，否则提示「请先设置申报开始和截止时间」；发布后批次变为「申报中」并开始接收申报 |
| 开始评审 | 状态为「申报中」 | 批次变为「评审中」，提示「已进入评审阶段」 |
| 结束 | 状态为「申报中」或「评审中」 | 批次变为「已结束」 |
| 删除 | 始终 | 确认「确认删除该批次？」；**批次下存在申报记录或结果公示时拒绝删除** |

> 系统每 10 分钟自动把「申报中」且已过申报截止时间的批次改为「评审中」。

### 4.6 申报管理（列表）

- 筛选：「搜索项目名称」+ 批次下拉（全部批次）+ 状态下拉（全部状态 + 9 种申报状态）+「查询」。
- 列表列：ID / 项目名称 / 申报人 / 批次 / 状态 / 评审平均分 / 操作。
- 行操作：
  - **「详情」**：进入申报详情页（所有后续流程都在详情页完成）。
  - **「初审通过」/「初审驳回」**：仅状态为「待初审」时出现，**不弹意见框，直接以「初审通过」/「初审不通过」作为意见**提交，提示「初审完成」。需要写具体意见时请进入详情页操作。

### 4.7 申报详情（管理端）

这是管理人处理申报的**主操作页**。

**（1）基本信息**：申报人 / 所在单位 / 申报批次 / 项目类别 / 项目名称 / 提交时间 / 公示时间 / 项目简介 / 申报内容。

**（2）申报材料**：材料名称 / 类型 / 大小 / 操作（「下载」）。

**（3）初审意见**：初审后出现，显示意见内容（驳回为红色）。

**（4）专家评审**：评审人 / 状态 / 评分 / 评审意见；已有人评分时显示「综合平均分：{分数}（{已评分数}/{评审总数} 位专家已评分）」，否则「暂无专家评分」。

**（5）评审结果**：确定结果后出现。

**（6）证书**：颁发后出现，显示证书编号 / 证书名称 / 持有人 / 颁发时间，并提供「下载证书」（需已上传文件）与「作废证书请前往证书管理」（跳转证书管理页）。

**（7）操作区**（草稿与初审驳回状态不显示）

> 若申报处于「待评审」且**没有任何评审人**（或评审人已全部移除），页面顶部会出现提示「该申报当前没有评审人（或评审人已全部移除），可直接确定评审结果结案」，此时可直接确定结果。

| 环节 | 按钮 | 显示条件 | 说明 |
| --- | --- | --- | --- |
| 初审 | 初审通过 / 初审驳回 | 待初审 | 打开「填写意见」弹窗（初审意见可留空） |
| 评审 | 分配评审 | 待评审 / 评审完成 | 打开「分配评审专家」弹窗 |
| 结果 | 确定通过 / 确定不通过 | 评审完成；或待评审且无未评分评审人 | 打开「填写意见」弹窗，确定后提示「评审结果已确定」 |
| 公示 | 公示结果 | 已通过 / 未通过 且尚未公示 | 提示「结果已公示」 |
| 公示 | 结果已公示（标签） | 已通过 / 未通过 且已公示 | 纯展示 |
| 公示 | 撤回评审结果 | 已通过 / 未通过（未公示） | 确认「撤回评审结果后，申报将回到「评审完成」，需重新确定结果，确认撤回？」→ 退回「评审完成」并清空结果意见 |
| 公示 | 撤回公示 | 已公示 | 确认「撤回公示后，该结果将不再对申报人公开展示，确认撤回？」→ 退回「已通过」并清空公示时间 |
| 证书 | 颁发证书 | 已公示 | 打开「颁发证书」弹窗 |
| 证书 | 证书已颁发（标签）+ 前往证书管理 | 已发证 | 已发证不可再撤回结果，需先在证书管理作废证书 |

**「分配评审专家」弹窗**

- 多选下拉「请选择评审人（不选=清空评审人）」，可选的是「启用」中的评审人；已停用但仍被分配的评审人会显示为「某某（已停用）」。
- 提示：「取消勾选可移除未评分的评审人；已有评分的评审人无法移除」。
- 若不选任何人并确定，会二次确认「未选择任何评审人，将移除全部未评分的评审人，确认？」，成功后提示「已清空评审人」。
- 其他可能提示：「该批次评审已截止，不能再新增评审人」「已有专家完成评分，不能清空评审人」「{姓名}已完成评分，无法移除」。

**「颁发证书」弹窗**

| 字段 | 说明 |
| --- | --- |
| 证书编号 | 留空自动生成 `CAAM-年份-申报ID`（6 位补零） |
| 证书名称 | 留空则使用项目名称 |
| 持有人 | 留空则使用申报人姓名 |
| 证书文件 | 可直接粘贴地址或点「上传」选择文件（pdf/doc/docx/xls/xlsx/jpg/jpeg/png） |

点击「颁发」后提示「证书已颁发」，申报状态变为「已发证」，申报人收到站内通知。

### 4.8 评审管理（管理人视角）

- 筛选：状态下拉（全部状态、待评审、评审完成）。
- 列表列：项目名称 / 申报人 / 状态 / 评审平均分 / 操作。
- 行操作：「分配/评审」跳转到该申报的详情页进行分配与结果处理。

### 4.9 我的评审（评审人视角）

评审人登录后，侧边栏「我的评审」打开的是同一个页面，但界面不同。

- 筛选：状态下拉（全部状态、待评审、已评分）。
- 列表列：项目名称 / 所属批次 / 状态 / 我的评分 / 操作。
- 行按钮文字随状态变化：未评分显示「**评审**」，已评分显示「**查看**」，均进入打分页。

> 为保证评审独立性，评审人只能看到**分配给自己**的任务与项目内容：看不到其他申报、其他评审人的分数/意见，也看不到当前平均分与初审/终审意见（这些字段接口不下发）。

### 4.10 专家评审（打分页）

- 项目信息：项目名称 / 所属批次 / 项目类别 / 项目简介 / 申报内容。
- 申报材料：材料名称 / 操作（「下载」）。
- 评审打分：**评分**（0–100，保留 1 位小数，可点上下箭头调整）+ **评审意见**（多行文本）→「提交评审」，成功提示「评审提交成功」。
- 「返回」回到任务列表。

> 评分提交后该任务变为「已评分」，「提交评审」按钮置灰不可再次提交；批次评审截止后提交会被拒绝（「该批次评审已截止」）。全部评审人评分完成后，申报自动进入「评审完成」，申报人会收到「评审已完成」通知。

### 4.11 评审任务

管理端的全部评审任务总览。

- 筛选：「搜索项目名称」+ 批次下拉 + 评审人下拉 + 状态下拉（全部状态、待评审、已评分）+「查询」。
- 列表列：任务ID / 项目名称 / 申报人 / 所属批次 / 评审人 / 状态 / 评分 / 评审时间 / 操作。
- 行操作：「查看申报」跳到对应申报详情页。

### 4.12 结果公示

管理端在这里维护「公示公告」（自由文本），并可用逐条结果一键生成正文。

- 筛选：「搜索公示标题」；右上角「新增公示」。
- 列表列：公示标题 / 所属批次 / 状态（已发布、草稿）/ 操作。

| 操作 | 说明 |
| --- | --- |
| 编辑 | 已发布的公示不可编辑（置灰） |
| 发布 | 仅草稿显示；提示「已发布」，发布后不可编辑、不可删除 |
| 删除 | 已发布的公示不可删除（置灰）；确认「确认删除该公示？」 |

**新增 / 编辑弹窗**：公示标题、所属批次（可搜索）、公示内容；正文上方有「**引用该批次已公示的评审结果**」按钮（需先选择批次）——点击后自动生成正文：

```text
本批次共受理并公示 N 个项目，其中通过 M 个：

1. 项目名称（申报人：张三）——通过
2. 项目名称（申报人：李四）——未通过
```

提示「引用后仍可手工调整；逐条结果公示与公告现在是同一批数据」。引用成功后如需标题会自动填为「{批次名称}评审结果公示」。

> 「逐条结果公示」无需在此维护：只要在申报详情中执行过「公示结果」，该条结果就会自动出现在申报人端的「结果公示 → 评审结果」中。

### 4.13 证书管理

- 筛选：「搜索证书编号/名称/持有人」；右上角「颁发证书」。
- 列表列：证书编号 / 证书名称 / 持有人 / 所属项目 / 状态 / 操作。

| 操作 | 说明 |
| --- | --- |
| 下载 | 仅在该证书已上传文件时显示 |
| 编辑 | 已作废证书不可编辑（置灰） |
| 作废 | 已作废证书不可再作废（置灰）；弹窗「作废证书」要求填写作废原因（可留空，如「信息填写错误」）；确认后提示「证书已作废」 |

**颁发 / 编辑弹窗**：关联申报（仅新增时可选，**只列出已公示的申报**；无可选项时提示「暂无可颁发证书的申报（需已公示且通过）」）、证书编号、证书名称（必填）、持有人、证书文件。保存校验：无证书名称提示「请填写证书名称」；新增未选关联申报提示「请选择关联申报」。

> **作废后**：证书状态变为「已作废」，申报人端不再显示该证书，对应申报退回「已公示」，可重新颁发（原编号会被释放）。

### 4.14 通知管理

向申报人发送站内通知（一次性发送，发送后不可撤回）。

| 字段 | 说明 |
| --- | --- |
| 通知对象 | 「全部申报人」（默认）或「指定申报人」 |
| 选择申报人 | 仅「指定申报人」时显示，下拉可搜索，显示「姓名（用户名）」 |
| 通知标题 | 必填 |
| 通知内容 | 必填 |

点击「发送通知」后提示「通知已发送」，标题与内容被清空（通知对象选择保持不变，便于连续发送）。

### 4.15 申报人管理

- 筛选：「搜索用户名/姓名/单位」；右上角「新增申报人」。
- 列表列：ID / 用户名 / 姓名 / 单位 / 电话 / 状态 / 操作。

| 操作 | 说明 |
| --- | --- |
| 编辑 | 弹窗字段：用户名（编辑时不可改）、密码（留空不修改）、姓名、电话、邮箱、单位 |
| 禁用 / 启用 | 按钮文字随状态变化，无确认框，提示「状态已更新」；被禁用账号登录时提示「账号已被禁用」 |
| 删除 | 确认「确认删除该申报人？」；**该申报人已有申报记录时拒绝删除**（保留申报归属） |

### 4.16 账号管理（仅超级管理员）

- 筛选：「搜索用户名/姓名」；右上角「新增账号」。
- 列表列：ID / 用户名 / 姓名 / 角色 / 电话 / 操作。
- 「新增账号」不提供「评审人」选项，弹窗内有提示「评审人账号请通过「专家库」新增，以保证账号与专家档案一一对应」；编辑一个已是评审人的账号时会临时保留该选项，避免保存时角色被清空。
- 「删除」：确认「确认删除该账号？」；**该账号存在评审任务时拒绝删除**；若该账号是专家库账号，会连同其专家档案一起删除。

### 4.17 系统日志

只读的管理端操作日志。

- 筛选：「搜索操作/管理员」+ 模块下拉（全部模块、批次管理、类别管理、初审管理、评审管理、结果公示、证书管理、用户管理、账号管理、通知管理）+「查询」。
- 列表列：ID / 操作人 / 模块 / 操作 / IP / 时间（无行操作）。

### 4.18 个人资料（管理端）

- **个人资料**：用户名（不可改）、姓名、角色（不可改，显示为超级管理员/管理人/评审人）、电话、邮箱 → 「保存资料」。
- **修改密码**：原密码、新密码 → 「修改密码」，成功后提示「密码修改成功」。

## 五、全流程速查

### 5.1 一次完整申报的生命周期（管理方视角）

```text
① 类别管理         新建项目类别
② 批次管理         新建批次 → 填好类别/申报窗口/评审截止 → 发布（批次变为「申报中」）
③ 申报人           浏览「可申报项目」→ 立即申报 → 填信息 → 上传材料 → 提交申报
④ 申报管理/详情     初审通过 → 状态「待评审」（驳回则申报人可在申报期内修改后重新提交）
⑤ 申报详情          分配评审专家（可先建「专家库」专家）
⑥ 专家评审          评审人登录 → 我的评审 → 评审打分 → 提交评分
⑦ 申报详情          全部评分完成 → 状态「评审完成」→ 确定通过 / 确定不通过
⑧ 申报详情/结果公示  公示结果（逐条）＋ 结果公示页发布公告（可选，可一键引用逐条结果）
⑨ 证书管理/申报详情  颁发证书 → 状态「已发证」，申报人可下载
```

### 5.2 常见状态含义（给申报人的解释口径）

| 状态 | 含义 | 申报人可做什么 |
| --- | --- | --- |
| 草稿 | 尚未提交 | 修改信息、上传/删除材料、提交、删除 |
| 待初审 | 已提交，等待管理人初审 | 撤回（撤回后回到草稿） |
| 初审驳回 | 初审未通过 | 在申报截止前修改信息/材料后重新提交 |
| 待评审 | 初审通过，等待专家评分 | 等待，可在详情页看到各专家评分进度 |
| 评审完成 | 全部专家已评分 | 等待管理人确定结果 |
| 已通过 / 未通过 | 结果已确定（尚未公示） | 等待公示 |
| 已公示 | 结果已对外公示 | 查看「结果公示」页 |
| 已发证 | 已颁发证书 | 在「我的证书」下载 |

## 六、常见问题与注意事项

### 6.1 常见问题

| 现象 / 提示 | 原因与处理 |
| --- | --- |
| 管理端账号在申报人登录页登录失败 | 属预期：两套账号体系（`application_users` / `application_admins`）互不通用，请从对应入口登录 |
| 提示「验证码错误」 | 验证码 5 分钟有效且校验一次即作废，请点击验证码图片刷新后重新输入 |
| 提示「请求过于频繁，请稍后再试」 | 按真实 IP 限流：验证码 30 次/分钟、注册/登录 10 次/分钟、上传 20 次/分钟（另有单 IP 并发上限），稍等片刻重试 |
| 提示「请填写完整信息（含验证码）」 | 注册时未填验证码，点击验证码图片获取后重新提交 |
| 提示「用户名已存在」 | 注册或新增账号时用户名被占用 |
| 提示「账号已被禁用」 | 账号被管理方停用，请联系管理方 |
| 提示「该批次不在申报期内」/「该批次已截止申报」 | 批次状态不是「申报中」，或当前时间不在申报窗口内 |
| 提示「请在申报截止前上传申报材料」/「请先上传申报材料」 | 提交申报前至少要有一份材料 |
| 提示「仅草稿或初审驳回状态可编辑」 | 该状态下不允许修改，如需修改请联系管理人 |
| 提示「审核中/已发布不可编辑」类似提示 | 申报已进入后续流程，只能查看 |
| 提示「该批次评审已截止，不能再新增评审人」 | 批次「评审截止」时间已过；移除未评分评审人仍可操作 |
| 提示「{姓名}已完成评分，无法移除」 | 已评分评审人不可移除（避免平均分失真） |
| 提示「还有 N 位评审人未评分，无法确定结果」 | 需等待评分完成，或用分配弹窗移除未评分的评审人 |
| 提示「该申报已颁发证书，请先在「证书管理」中作废证书」 | 已发证不可直接撤回公示 |
| 提示「该专家/账号存在评审任务，无法删除」 | 先把相关评审任务处理掉，或改为「停用」 |
| 提示「该批次下存在申报记录，无法删除」/「该类别下存在申报批次，无法删除」 | 存在下级引用，需先处理下级数据 |
| 「上传材料」被拒绝 | 检查类型是否在白名单内、单文件是否超过 50MB |
| 申报人看不到证书 | 证书可能已被作废；或尚未颁发 |
| 页面能打开但接口 404 | 部署子路径与接口前缀不一致，请管理员核对 `server.api_prefix` 与 `VITE_API_BASE_URL` |
| 提示「…状态已变更，请刷新后重试」 | 并发/重复操作：另一个人（或另一个标签页）已把该申报/批次推到下一步，刷新看最新状态即可（属并发保护，非故障） |
| 提示「材料数量不能超过 20 份」 | 单份申报的材料上限为 20 份，先删掉不需要的材料再上传 |

### 6.2 注意事项

1. **提交前先确认批次窗口**：批次一过申报截止时间会自动转「评审中」，届时无法再提交或改材料。
2. **撤回有代价**：撤回后申报回到草稿，需在申报截止前重新提交；材料与信息不会丢失。
3. **删除申报不可恢复**：系统采用物理删除，申报记录与已上传材料文件会一并删除。
4. **公示公告发布后不可修改、不可删除**：请在发布前仔细核对内容。
5. **证书作废保留痕迹**：作废记录不会删除，仅标记为「已作废」，且会通知持有人。
6. **评审人账号一律从「专家库」创建**：账号与专家档案一一对应，删除时两者成对删除。
7. **密码安全**：管理端与申报人端均建议首次登录后立即修改默认密码；系统不会明文保存密码（bcrypt 哈希）。
8. **会话 24 小时**：Token 过期或账号被禁用后会立即失效（需重新登录）。
