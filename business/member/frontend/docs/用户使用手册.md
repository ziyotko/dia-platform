## 一、系统概述

会员系统面向协会的会员服务全流程，由三个层次组成，共用一个后端接口与一套账号体系：

| 层次 | 入口 | 使用者 | 主要能力 |
| --- | --- | --- | --- |
| **公开门户** | 站点根路径（如 `/business_member/`） | 未登录访客 | 首页与入会流程介绍、公告动态、协会章程、注册与登录 |
| **会员中心** | `/member/...`（登录后） | 已注册会员、正式会员 | 入会申请、会费缴纳与开票、证书下载与续证、加入机构、投稿文章、留言反馈 |
| **管理后台** | `/admin/...`（管理员登录后） | 协会管理员 | 入会审核、会员与会费管理、证书发放、组织与等级/会费标准配置、内容管理、系统维护与审计 |

**业务主线（五步入会）**：注册账号 → 提交入会申请（打印签字盖章后上传） → 协会审核 → 按等级缴纳年度会费 → 成为正式会员并颁发证书。

**账号体系**：所有账号（含管理员）都存放在同一张会员表中，管理员是 `is_admin = true` 的会员账号。管理员登录后会额外在会员中心右上角下拉中看到「管理后台」入口。

> **权限说明**：公开页面无需登录；`/member/**` 需要登录；`/admin/**` 需要管理员身份。非管理员访问后台地址会被自动跳回会员首页。

## 二、访问与账号

### 2.1 访问方式

在浏览器中打开协会提供的部署地址即可。系统通常部署于 Nginx 站点的子路径下（默认 `/business_member/`），实际地址以管理员提供的为准。

### 2.2 浏览器要求

建议使用 Chrome / Edge / Firefox 等现代浏览器的最新版本，并开启 JavaScript 与 Cookies。

### 2.3 注册账号

点击页面右上角「注册账号」（或首页「入会流程」第 1 步的「立即注册」）进入注册页，按步骤条完成 **账户注册 → 填写资料 → 确认提交**。

**第 1 步：账户注册**

| 分区 | 字段 | 填写要求 |
| --- | --- | --- |
| 账户信息 | 用户名 | 必填，最长 20 位，**只能包含小写字母、数字、`-` 和 `_`**，系统自动查重 |
| | 密码 | 必填，8~20 位，需**同时包含小写字母、大写字母、数字、特殊字符** |
| | 再次输入密码 | 必填，需与密码一致 |
| 联系方式 | 手机号 | 必填，11 位手机号，系统自动查重 |
| | 邮箱 | 必填，最长 40 位，需符合邮箱格式，系统自动查重 |
| 会员类型 | 单位会员 / 个人会员 | 单选，默认「单位会员」（决定第 2 步是否需要填写单位信息） |

**第 2 步：填写资料（仅「单位会员」需要）**

- 单位全称（必填，查重）、统一社会信用代码（必填，18 位，按 GB 32100-2015 校验位校验+查重）、法定代表人姓名（必填）、联系人姓名（选填）、单位详细地址（选填）；
- 资质文件：上传「组织机构证」，支持 `jpg / png / pdf`，只能上传 1 个文件，选择后自动上传；
  > 提示：此项在注册页**未做强制校验**，可以跳过；但**发起入会申请时**若仍未上传，会被提示"请先上传组织机构代码证，补全会员信息后再发起申请"。

**第 3 步：确认提交**

- 核对「账户信息」「单位信息」卡片内容（未填写的显示"未填写"、未上传的显示"未上传"）；
- 输入**图形验证码**（看不清可点击图片刷新）；
- 点击「确认提交」，成功后自动登录并跳转到会员首页。
  > 个人会员注册**不采集姓名与身份证号**，需注册后在「会员中心 → 我的资料」中补全，否则无法发起入会申请。

**注册校验速查**

| 项目 | 规则与提示 |
| --- | --- |
| 用户名 | 请输入用户名 / 用户名不能超过20位 / 用户名只能包含小写字母、数字、- 和 _ / 该用户名已被注册 |
| 密码 | 请输入密码 / 密码不能超过20位 / 密码至少8位 / 密码需包含小写字母·大写字母·数字·特殊字符 |
| 确认密码 | 请再次输入密码 / 两次密码不一致 |
| 手机号 | 请输入手机号 / 手机号不能超过11位 / 请输入合法的手机号 / 该手机号已注册 |
| 邮箱 | 请输入邮箱 / 邮箱不能超过40位 / 邮箱格式不正确 / 该邮箱已注册 |
| 单位名称 | 请输入单位名称 / 该公司名称已存在 |
| 统一社会信用代码 | 请输入统一社会信用代码 / 统一社会信用代码格式不正确 / 统一社会信用代码校验不通过 / 该统一社会信用代码已存在 |
| 法定代表人 | 请输入法定代表人姓名 |

### 2.4 登录

1. 输入**用户名**；
2. 输入**密码**（可点右侧眼睛图标查看明文）；
3. 输入**验证码**（5 位，**不区分大小写**，**一次性使用**，输错后页面会自动刷新出新验证码；点击图片可手动刷新）；
4. 点击「登 录」或按回车。

登录成功后：管理员自动进入**管理后台首页**，其他会员进入**会员中心首页**。

> **系统不提供「忘记密码」自助找回功能**。忘记密码请联系协会管理员，由管理员在「会员管理 → 重置密码」中重置为默认密码 `Abcd@1234`，随后请及时自行修改。

### 2.5 退出登录

- 会员中心：右上角头像 →「退出登录」，退出后回到公开门户首页；
- 管理后台：右上角头像 →「退出登录」。

### 2.6 内置账号（初始）

系统首次启动会创建默认管理员：

| 用户名 | 初始密码 | 说明 |
| --- | --- | --- |
| `admin` | `Abcd@1234` | 管理员（可登录后台），**上线后请立即修改密码**；后台「重置密码」也是重置为该密码 |

## 三、公开页面

### 3.1 首页

首页由两块内容组成：

1. **头图区**：徽章文字"全国性行业社会团体 · 会员服务平台"，主标题为站点名称，副标题"服务政府 · 服务行业 · 服务企业"，描述文字取自后台「系统管理」中的站点描述。
2. **入会流程**：五步图示，其中两步带按钮可直接跳转：

| 步骤 | 说明 | 按钮 | 跳转 |
| --- | --- | --- | --- |
| 1 注册账号 | 在线注册成为注册会员 | 立即注册 | 注册页 |
| 2 入会申请 | 提交入会申请表，签字盖章后上传 | 发起入会申请 | 会员中心「我的申请」（未登录会先跳登录） |
| 3 协会审核 | 协会对申请资料进行审核 | — | — |
| 4 缴纳会费 | 审核通过后按会员等级缴纳年度会费 | — | — |
| 5 成为会员 | 颁发会员证书，享会员权益与服务 | — | — |

顶部导航为「公告动态」「协会章程」，右侧为「会员登录」与「注册账号」。页脚展示版权所有者、ICP 备案号、网安备案号（均来自后台配置）。

### 3.2 公告动态

- 列表支持关键词搜索（标题/正文），每页 10 条；
- 每条显示：置顶标记（红色「置顶」标签）或类型标签（通知 / 文章 / 政策）、标题、发布日期；
- 点击任意一条进入详情，详情显示标题、发布日期、浏览次数与正文（正文已做安全过滤）；
- 404 或已删除的公告显示"公告不存在"，可点「返回列表」。

### 3.3 协会章程

- 页面顶部有阅读进度条，正文由协会管理员用富文本编辑器维护；
- 可用操作：
  - **打印本章程**：调用浏览器打印（有正文时可用）；
  - **下载章程 PDF**：仅当协会已上传 PDF 附件时显示；
  - **返回上一页**、右下角**回到顶部**。
- 若尚未维护，页面显示"章程暂未维护，请联系管理员"。

## 四、会员中心

登录后进入会员中心，左侧菜单共 9 项；右上角头像下拉可进入「个人资料」、管理员可见的「管理后台」，以及「退出登录」。

### 4.1 会员首页

- **欢迎卡**：按时间显示问候语（早上好/上午好/中午好/下午好/晚上好/夜深了），显示会员名称、入会机构与等级徽章、会员状态与类型；并按状态显示快捷按钮：
  - 状态为"注册会员"→「申请入会」；
  - 状态为"待缴费"→「立即缴费」；
  - 始终可用「编辑资料」。
- **快捷入口**：我的申请、会费管理、我的证书、我的文章、会员留言、加入信息。
- **数据卡片**：我的申请（最新申请状态）、未读消息数、我的文章数、已缴年数。
- **最新公告**：最近 5 条，可「查看全部」，点击进入公告详情。
- **基本信息**：单位名称（单位会员）、联系人姓名、手机号码、电子邮箱、会员类型（未设置显示"未设置"）。
- **会费概览**：缴费进度条（已缴/应缴年数）、已缴年数、待缴年数、累计缴费金额；有待缴时显示「去缴费」按钮。

**会员状态含义**

| 状态 | 含义 |
| --- | --- |
| 注册会员 | 已注册，尚未提交入会申请 |
| 入会待审核 | 已提交申请，等待协会审核 |
| 待缴费 | 申请已通过，等待缴纳年度会费 |
| 正式会员 | 会费已确认，可下载证书、投稿文章 |
| 已拒绝 | 入会申请被拒绝 |
| 已过期 | 会籍已过期（由管理员置为，可恢复） |

### 4.2 我的资料

- **只读项**：用户名、会员类型、会员等级（未设置显示"暂无"）。
- **可修改项（单位会员）**：手机号、邮箱、单位名称、组织机构代码证（统一社会信用代码）、法定代表人、所属行业、成立日期、注册资本、员工规模、联系人、联系人职务、联系人手机号、单位地址、网站、经营范围、邮编、简介，以及**组织机构证**的查看/重新上传。
- **可修改项（个人会员）**：手机号、邮箱、姓名、身份证号、简介。
- **校验规则**：手机号/邮箱格式与**查重**（被其他账号占用会提示"该手机号/邮箱已被其他用户使用"）；单位名称、统一社会信用代码查重；身份证号按 18 位 + 出生日期 + 校验码校验；**未修改的字段不会触发查重**，避免误报。
- 上传组织机构证支持 `jpg / png / pdf`，单文件不超过 10MB，上传成功提示"证照上传成功，请点击保存修改以确认"。
- 点击「保存修改」提交。
- **修改密码**：点「修改密码」弹出对话框，输入「原密码」「新密码」后点「确认修改」。
  > 注意：该弹窗仅两个输入框，未做长度与强度校验，两个输入框任一为空时不会提交也不提示。

> 会员端**不提供头像上传**；首页头像由名称首字符自动生成。

### 4.3 我的申请

- 列表显示：编号、申请分会（机构）、状态、审核意见、申请时间；**待审核**的记录可「撤回」。
- 右上角「发起入会申请」按钮在满足以下任一条件时会被隐藏，页面顶部同时显示对应提示：

| 情形 | 提示 |
| --- | --- |
| 已通过审核 | 您已通过入会审核，不允许重复申请入会（如需加入其他分支机构或代表机构，请到「加入信息」页面申请加入） |
| 已有待审核申请 | 您已有待审核的入会申请（审核完成或先撤回后才能重新提交） |
| 已是正式会员 | 您已是正式会员，无需再次申请入会 |

- **发起入会申请（三步弹窗）**：
  1. **填写信息**：选择申请入会的机构（总会或分会，下拉显示机构简介；选到分会时会提示"加入任何一个分会默认都会加入总会"），可下载「入会章程」；单位会员还会带出单位名称、信用代码、联系人、单位地址；
  2. **确认资料**：核对信息，下载「会员申请表」，打印后签字盖章；
  3. **上传文件**：上传签字盖章后的申请表扫描件（支持 PDF / JPG / PNG，多页扫描件可打包为 ZIP/RAR 上传，单文件不超过 10MB）；
  - 点击「提交申请」完成，未选择机构或未上传文件会有对应提示。
- **撤回**：确认后该待审核申请会被**直接删除**，之后可重新提交。

> **提交前置条件**：单位会员需先上传组织机构代码证，个人会员需先补全姓名与身份证号，否则会被拦截并跳转到「我的资料」。

### 4.4 会费管理

- 顶部可「筛选年度」（当年 +3 年至当年 -5 年，共 9 项）。
- **协会账户信息**提示条展示开户银行、账号、户名，并提示：请先联系相关单位确定最终会员级别和缴费金额再汇款，汇款时备注栏注明"XX 年度会费"及单位名称。
- 列表字段：入会信息（机构）、会员级别、年度、金额、状态、缴费日期、票据号码、发票状态、开票单位全称、开票金额、开票时间、开票备注、操作。

| 情形 | 可执行操作 |
| --- | --- |
| 未缴费且未设置会员级别 | 按钮禁用，提示"会员级别为空，请先联系管理员修改会员级别" |
| 未缴费 | 「缴费」 |
| 待确认 | 显示"待确认"标签，等待管理员确认 |
| 已缴费、未申请开票、实缴金额 > 0 | 「申请开票」 |
| 已缴费、实缴金额为 0 | 显示"实缴为0"，不能申请开票 |
| 已开票 | 「下载发票」 |

- **缴费（提交缴费凭证）**：填写「缴费日期」（必填）、上传「缴费回执单」（必填，PDF/PNG/JPG），提交后状态变为"待确认"，提示"缴费信息已提交，等待管理员确认"。
- **申请开票**：填写开票单位全称、统一社会信用代码、开票金额（上限为实缴金额）、开票联系人及电话（均必填），开票备注选填；表单会自动带出资料中的单位名称、信用代码与联系人信息。

### 4.5 我的证书

- 列表显示：证书编号、颁发日期、会员级别、有效期至、状态、操作。
- **下载证书**：仅"正式会员"可下载；证书文件尚未生成时提示"证书文件暂未生成，请联系管理员"。
- **刷新（重新生成证书）**：当前账号为正式会员、且当前没有"有效"证书时出现（例如旧证书已失效/过期），确认后系统重新生成一张新证书。
- **续证条件（服务端校验）**：正式会员 + 当年已缴费 + **当前不存在有效证书**（或有效证书的 PDF 尚未生成）。已有有效证书时调用会返回"当前已有生效证书，无需重复续证"，避免重复发证/刷证。

### 4.6 加入信息（加入的组织机构）

- 以卡片形式展示已加入的机构：机构名称、机构简介（过长可「展开/收起」）、级别标签、加入方式标签（**缴费加入** / **主动加入**）、加入时间。
- **退出**：仅"主动加入"的分支机构/代表机构可退出（总会与缴费加入的机构不显示退出按钮）；确认后提示"已退出"。
- **新的加入**：右上角按钮，在没有任何"缴费加入"的机构时禁用（提示"暂无缴费加入的组织，无法加入新组织"）。
  - 弹窗内可搜索机构、展开机构树选择目标机构（已加入或层级不可选的节点会显示"已加入"/"不可加入"并禁用）；
  - 选中后显示机构简介，并需**选择会员级别**（可选同级或更低等级，标签显示"同级"/"低级"）；
  - 确认后提示"加入成功"。

### 4.7 我的文章

- 支持按「状态」「分类」筛选，变更筛选后自动回到第 1 页；列表每页 10 条。
- 列表字段：标题、分类、状态、创建时间、操作（编辑 / 浏览 / 删除）。

| 状态 | 含义 |
| --- | --- |
| 草稿 | 已保存未提交，可继续编辑或提交 |
| 待审核 | 已提交，等待管理员审核 |
| 已发布 | 审核通过，公开展示于「服务中心 → 会员文章」 |
| 已拒绝 | 审核未通过，可按审核意见修改后重新提交 |

- **发布/编辑文章**：填写标题（必填）、分类、封面图（上传后即时生效）、摘要、正文（富文本编辑器，支持标题、列表、表格、图片、引用等）。按钮：
  - 「保存草稿」（已发布的文章不显示）；
  - 主按钮：新建/修改未发布文章时为「立即提交」；编辑**已发布**文章时为「提交修改（需重新审核）」（保存后文章会回到待审核状态，需重新审核发布）。
- **浏览**：弹窗预览封面、摘要、正文。
- **删除**：确认后删除，不可恢复。
  > 当前版本**没有「撤回」待审核文章**的功能。

### 4.8 会员留言

- 列表显示标题、内容摘要、回复（未回复显示"暂无回复"）、状态、时间；
- 点击任意一行打开详情；**未读留言在打开详情时会自动标记为已读**；
- 「新建留言」：填写标题与内容（均必填），提交后提示"留言成功"；
- 详情中可查看管理员回复内容与回复时间。

### 4.9 服务中心

以页签形式提供三类公开内容：

1. **公告动态**：与公开公告列表一致，点击进入公告详情；
2. **会员文章**：显示各会员发布的已通过审核的文章（分类标签 + 标题 + 作者），点击弹窗阅读全文；
3. **协会章程**：展示章程正文，可「下载章程 PDF」（协会已上传附件时）或「在新页面打开」。

### 5.2 会员管理

**查询与新增**

- 筛选：关键词（用户名/公司名）、状态（注册中/待审核/待缴费/正式会员/已拒绝/已过期）、会员类型（单位会员/个人会员）；
- 「新增会员」用于线下发展的会员直接建账。

**列表**

- 列：ID、用户名、公司名称/姓名、类型、入会机构、会员等级、状态、操作。
- 行操作：

| 按钮 | 条件 | 说明 |
| --- | --- | --- |
| 所有会籍 | 始终 | 查看「付费加入」「主动加入」两类机构记录 |
| 变更等级 | 仅"正式会员" | 见下 |
| 状态变更 | 仅"正式会员"或"已过期" | 置为已过期 / 恢复会籍，见下 |
| 会籍历史 | 始终 | 按年度分组展示会籍变更时间线（滚动自动加载更多） |
| 重置密码 | 始终 | 重置为默认密码 `Abcd@1234` |
| 删除 | 仅"注册中" | 其他状态会提示"仅「注册中」状态的会员才可删除" |

- 点击行任意位置可打开**会员详情**（基本资料 / 单位信息 / 个人信息，含营业执照查看下载）。

**新增会员表单**

| 字段 | 校验 |
| --- | --- |
| 用户名 | 必填，查重（该用户名已存在），最长 32 |
| 密码 | 选填；填写时至少 6 位；**留空则使用默认密码 Abcd@1234** |
| 手机号 | 必填，11 位手机号，查重 |
| 邮箱 | 必填，最长 64，格式校验，查重 |
| 会员类型 | 单位会员 / 个人会员 |
| 公司名称 | 选填，查重 |
| 统一社会信用代码 | 必填（18 位，校验位校验），查重 |
| 联系电话 | 必填，手机号或固定电话（如 `010-12345678`），查重 |
| 姓名 / 身份证号 | 个人会员必填（身份证按 18 位 + 出生日期 + 校验码校验） |
| 总会 | 必填，默认选中第一个总会 |
| 会员等级 | 必填，选项来自该总会「关联等级」（总会未配置时会提示"该总会尚未关联会员等级，请先在「组织机构」中配置"） |
| 其他机构 | 选填，可多选该总会下的分支机构/代表机构，**自动沿用总会等级** |

> 新增会员会自动写入一条总会**免缴**会费记录、一张生效证书，以及一条会籍变更记录（原因"新增会员"）。
> 上述写入在**同一个事务**中完成：任一步失败都会整体回滚，不会留下"有会员无费用/无证书"的半成品。证书 PDF 在事务提交后生成（渲染较慢），生成失败不回滚会员创建，提示会写到后端日志，可在「证书管理」中重新生成。
> 说明：法定代表人、联系人、单位地址为选填且无格式校验。

**变更等级**

- 入口仅在会员状态为"正式会员"时可用；
- 弹窗显示「当前等级」，选择「新等级」（**只能选择该会员已缴费加入的机构所支持的等级**），并**必填「变更原因」**（≤500 字）；
- 新旧等级相同、未选择等级、非正式会员时都会给出对应提示。

**状态变更（到期 / 恢复会籍）**

- 入口仅在会员状态为"正式会员"或"已过期"时可用（其余状态由入会审批与缴费流程自动维护）；
- 弹窗显示当前状态，选择目标状态（正式会员 / 已过期）后二次确认；系统只接受这两个目标值。
- 置为"已过期"：会同步**作废该会员名下的生效证书**，并写入一条「会员到期」会籍记录；
- 恢复会籍：**不会**自动恢复证书，会员缴费后可自行「刷新」证书，并写入一条「恢复会籍」会籍记录。

### 5.3 会籍记录（会籍变更记录）

- 筛选：关键词（用户名/公司名/等级）、会员类型、变更年份（选项由系统按已有数据动态生成）；
- 「导出」按钮导出 CSV（文件名形如 `member_level_changes_时间戳.csv`）；
- 列：变更用户名、公司名称/姓名、类型、变更时间、变更年份、入会机构、原始会籍（无显示 `-`）、新的会籍（已失效显示灰色"已失效"）、变更原因、变更人；点击行可查看会员详情。

**会籍记录的产生来源**（便于核对台账）：

| 原因 | 触发时机 |
| --- | --- |
| 新增会员 | 管理员新增会员 / 入会审批通过 |
| 缴费确认 | 会费记录首次变为"已缴费"（同年同机构同等级只记一条） |
| 退出机构 | 会员主动退出某机构 |
| 会员到期 | 管理员将会员置为"已过期" |
| 恢复会籍 | 会员由"已过期"恢复为其他状态 |
| 证书续期 | 会员自助刷新（重新生成）证书，每年最多一条 |
| （管理员自定义） | 后台「变更等级」时填写的原因 |

### 5.4 资料记录（资料变更记录）

- 筛选：关键词（修改人/字段名称）；不支持导出。
- 列：用户名、修改人、字段、原始内容、变更后内容、变更时间；点击行查看会员详情。
- 记录口径：**一个字段一行**（会员一次修改多个字段会产生多条记录），只增不改；密码类字段不记录。

### 5.5 入会审核

- 状态筛选：全部 / 待审核 / 已通过 / 已拒绝；
- 列：ID、申请单位/个人、用户名、申请总会/分会、类别、状态、申请时间、操作；
- 「查看」打开申请单位信息（含证照下载、入会申请书下载）；
- 对待审核记录可执行：

| 操作 | 说明 |
| --- | --- |
| 通过 | 弹出输入框填写审核意见（可选）；确认后申请置为"已通过"，会员状态变为"待缴费" |
| 拒绝 | 弹出输入框填写**拒绝理由（必填，不能只填空格）**；确认后申请置为"已拒绝"，会员状态变为"已拒绝"，理由会保存在申请的「审核意见」中供会员查看 |

**审批通过后系统自动完成**：会员自动加入**总会**（若申请的是分会/代表机构，同时写入该机构的主动加入关系）；按总会**关联等级中等级最低**的一项确定会员等级（总会未配置等级时回退申请机构自身的等级）；生成当年会费记录（状态"未缴费"，该会员当年已有费用记录时跳过创建）；生成一张生效证书（并作废原生效证书）；写入一条"新增会员"会籍记录。

> **前置要求**：总会（或该申请机构）必须已在「组织机构」中配置**关联等级**，否则审批会被拒绝并提示"机构尚未配置会员等级，请先在后台「组织机构」中为总会（或该申请机构）关联会员等级，再审核通过"（旧版本会默默生成一条无等级的会费记录，导致会员端无法缴费）。
> 另：会费标准未配置时会按默认金额 2000 元/年创建记录（日志中有 Warn 提示），建议提前在「会费标准」中配置。

### 5.6 会费管理

- 顶部 6 张统计卡：总记录数、已缴费、未缴费、待确认、总金额、实缴总金额；
  > 说明：卡片数据由后端聚合下发（`GET /admin/fees` 的 `summary`），按**年度 + 会员类型**过滤，**不受“缴费状态”筛选与分页影响**（卡片本身即状态拆分）；翻页时数字不会变化。
- 筛选：年度（当年 +3 年至当年 -9 年，共 13 项）、缴费状态、会员类型；
- 行操作：

| 按钮 | 条件 | 说明 |
| --- | --- | --- |
| 编辑 | 未缴费 | 修改会员级别、金额、状态、备注；会员级别变更时会按"新级别 + 该年度"自动带出会费标准金额 |
| 缴费回执 | 有回执文件 | 新窗口打开回执 |
| 确认缴费 | 待确认 / 未缴费 | 填写「缴费金额」（默认=应收金额，填 0 即免缴）与「备注」后确认；写入实缴金额与确认时间，会员端可据此申请开票 |
| 免缴确认 | 未缴费 | 需填写备注（如"免缴"）；**不记入实缴金额**（会员端不可对该记录申请开票）；会员级别为空时按钮禁用并提示先修改级别 |
| 删除 | 未缴费 | 删除该费用记录 |
| 开票 | 已申请 | 填写票据号码并上传发票 PDF |
| 重新上传发票 | 已开票 | 更换票据号码/发票文件 |

- **新增费用**：按名称搜索选择会员 → 自动带出机构与级别 → 选择年度（会按"等级 + 年度"自动填充金额）→ 可调整金额与备注 → 创建。同一会员同一年度已存在记录时会提示"该会员本年度费用记录已存在"。

> **两个“标记已缴费”入口的区别**：
> - 「确认缴费」写入**实缴金额**与**确认时间**（默认取应收金额，可手改为实收金额，填 0 即免缴），会员端可据此申请开票；
> - 「免缴确认」仅置为已缴费并写入确认时间，**不记入实缴金额**（实缴为 0，会员端不可申请开票）；
> 因此线下已收款（会员未上传回执）时请用「确认缴费」并填写实收金额。

### 5.7 证书管理

**页签 1：证书发放记录**

- 筛选：关键词（证书编号/会员名称）、状态（有效/已过期）；
- 列：证书编号、会员、会员等级、颁发日期、有效期至、状态、证书文件（下载 / 未生成）、操作；
- 「重新生成 / 生成文件」：为单张证书重新渲染 PDF；
- 「补生成缺失证书」：批量为未生成 PDF 的历史证书补生成（一次最多 200 张），完成后提示生成与失败数量。

**页签 2：证书样式**

- 为每个会员等级配置一张证书样式（PDF 模板，**第 1 页作为底图**，会员数据居中套印在模板上）；
- 「新增样式」：填写样式名称、选择证书分类（会员等级，编辑时不可改）、上传 PDF 模板；所有等级都已创建时按钮禁用并显示"所有等级已创建"；
- 列表显示样式名称、所属等级、模板文件（可「查看PDF」；文件在服务器上缺失时显示红色「文件缺失」标签）；
- 未配置样式的等级在发证时使用系统默认版式。

### 5.8 组织机构

- 机构层级为**两层**：上级机构（总会/协会本体）→ 分支机构 / 代表机构；系统**只允许一个上级机构**，"新增上级机构"按钮仅在尚无机构时显示；
- 上级机构卡片：名称、"上级机构"标签、简介、已关联的等级标签，操作为「分支」「代表处」「编辑」；
- 下级机构行：类型标签（分支机构/代表机构）、名称、关联等级标签、简介，操作为「编辑」「删除」；
- 弹窗字段：
  - 上级机构：名称（必填）、简介（≤1024 字，展示在会员端与官网首页）、关联等级（多选，可清空）；
  - 下级机构：名称（必填，如"变压器分会"）、简介、排序、关联等级（多选）；
- 删除下级机构时，若该机构已被会员加入、或有入会申请、或有会费记录，系统会拒绝删除并说明原因；**上级机构不提供删除入口**。

> **重要**：「关联等级」决定该机构可发展的会员等级，也是入会/加入时可选等级的来源。总会**必须至少关联一个等级**，否则会员无法正常入会缴费。

### 5.9 会员等级

- 列表显示排序、等级名称、描述；操作为「上移」「下移」「编辑」「删除」（首行不可上移、末行不可下移）；
- 等级顺序**越小等级越低**（默认：会员单位 < 理事单位 < 副理事长单位 < 理事长单位）；「上移/下移」即调整该顺序；
- 新增/编辑：等级名称（必填）、描述；**等级名称不可重复**（重名会提示"该等级名称已存在"）；
- 删除等级前，系统会检查是否被会员、会费记录、证书、机构等级配置、证书样式等引用，被引用时拒绝删除。

### 5.10 会费标准

- 按会员等级分卡片展示，每张卡片可「新增年度」；
- 每行填写「缴费年度」（≥2000，且不超过当年 +10）与「会费金额（元/年）」（≥0），保存后状态显示"已保存"，改动未保存时显示"已修改"；
- 删除已保存的标准需二次确认；未保存的行可直接移除。

> 入会审批与「新增费用」都会按"等级 + 年度"查此表取金额；**未配置时会按默认金额 2000 元/年创建记录**，请尽早配置。
> 服务端边界：年度须在 **2000 ~ 当前年份+10** 之间、金额不得为负；已被会费记录引用的标准不可删除（会提示"该会费标准已被会费记录使用，无法删除"）。

### 5.11 会员留言

- 列表：会员、标题、内容摘要、回复（未回复显示"未回复"）、时间、操作；
- 操作：「回复」（未回复时）/「修改回复」（已回复时，会预填原回复内容）、「删除」（二次确认，提示"删除后不可恢复"）；
- 回复框最多 2000 字，空内容不可提交。

### 5.12 文章管理

- 列表：标题（点击查看全文）、来源单位/个人、作者、分类、状态、时间、操作；
- 待审核文章行显示「通过」「拒绝」：
  - 通过：确认后文章公开发布（显示于会员端「服务中心 → 会员文章」）；
  - 拒绝：需填写拒绝理由，会员可在"我的文章"中看到；
- 所有行均可「删除」（二次确认，删除后不可恢复）；
- 「分类管理」弹窗可新增/编辑/删除文章分类（分类名称 ≤30 字、排序 0~999），**分类下已有文章时不可删除**；分类是会员发布文章时的可选项。

### 5.13 公告管理

- 列表：标题、类型（通知/文章/政策）、置顶（是/否）、浏览、发布时间（未发布显示"未发布"）、操作；
- 「发布公告」/「编辑」弹窗：标题、类型、内容（富文本编辑器）、置顶开关；
- 保存即发布（提交时带"立即发布"），保存后前台「公告动态」与会员端立即生效；
- 删除需二次确认。

> 提示：列表中「置顶」列显示为是/否；置顶公告在公开端「公告动态」中优先展示。

### 5.14 协会章程

- **章程 PDF 附件**卡片：上传/替换/下载/移除章程 PDF（仅 PDF，≤20MB，文件头校验）；上传新文件会替换旧文件；会员端「入会章程」下载的就是该文件；
- **正文编辑器**：富文本编辑，工具栏**不支持插入图片/视频**（保存时会自动剔除正文中的图片/视频并提示，附件请使用上方 PDF 卡片）；
- 顶部操作：「预览」（弹窗预览会员端效果）、「前台查看」（新窗口打开公开章程页）、「保存」。

### 5.15 系统管理

- 以表格维护系统配置键值（配置项、配置值、说明、更新时间），可新增/编辑/删除；
- `charter_content`（章程正文）在此页**隐藏**，请到「协会章程」页维护；
- 常用配置项：`site_name`（网站名称）、`site_description`（网站描述）、`copyright_name`（版权所有者）、`icp_no`（ICP 备案号）、`beian_no`（网安备案号）、`contact_phone`/`contact_email`（联系方式）、`bank_name`/`bank_account`/`bank_account_name`（协会收款账户，会费页展示）、`charter_file`（章程 PDF 附件元信息，请勿手工编辑）；
- 键为必填且唯一，编辑时不可修改键名。

### 5.16 操作日志

- 筛选：关键词（操作人/路径/IP）；切换筛选后自动回到第 1 页；
- 列：操作时间、操作人、方法（POST/PUT/DELETE 彩色标签）、路径、状态（成功/失败）、IP、耗时；
- 点击行查看详情（含请求参数与响应结果）；
- 说明：仅记录后台（`/admin/**`）的**非 GET** 请求；请求参数中的口令等敏感字段会以 `***` 记录（不存明文）。

### 5.17 我的资料（管理端）

- 可更换头像（`jpg/png/gif/webp`，≤10MB）并修改手机号、邮箱（格式校验 + 查重，"身份"标签显示管理员/会员）；
- 「修改密码」需填写原密码、新密码（**至少 8 位**）与确认新密码，三者均有必填与一致性校验。

## 六、通用操作与交互约定

1. **登录态失效**：Token 过期或账号被禁用时，任意操作都会自动清除登录状态并跳回登录页，并提示"登录状态已失效，请重新登录"。
2. **统一错误提示**：所有接口错误由请求层统一弹出提示（业务错误、上传过大、请求过于频繁、服务不可用、网络异常等），页面内一般不再重复提示。
3. **分页**：列表默认每页 10 条，无每页条数切换控件；会员端「我的申请」「会费管理」为全量展示（无分页）。
4. **弹窗**：提交类弹窗需点击按钮关闭（点击遮罩不关闭）；查看类弹窗可点击遮罩关闭。
5. **二次确认**：删除、撤回、退出机构、重置密码等操作均需二次确认；删除类确认框标题为「警告」/「删除确认」，确认按钮为「确定」/「删除」。
6. **加载与空态**：页面加载时表格/卡片显示加载动画；无数据时显示"暂无 XX"。
7. **富文本内容安全**：公告、文章、章程的富文本内容在保存与展示时都会做安全过滤（去除脚本、事件属性、非位图内嵌图片），因此这些内容仅支持常规排版。
8. **文件地址**：上传的文件（证照、回执、发票、证书、模板、章程）统一由后端 `/business_member/uploads/**` 提供访问；上传单文件上限 10MB（章程 PDF 为 20MB），上传接口有频率限制（约 20 次/分钟）。除注册页（使用匿名专用上传接口，仅支持图片/PDF、固定存入证照目录）外，**其余上传均需登录**。
9. **上传内容校验**：图片、PDF、压缩包会上传**文件头校验**——文件真实内容与扩展名不一致时会返回"文件内容与扩展名不符"（例如把改名的网页文件当成图片上传）。
10. **浏览器标题**：页面标题自动显示为「站点名称 - 当前菜单」，站点名称取自后台配置。

## 七、常见问题与注意事项

### 7.1 常见问题

| 问题 | 原因与处理 |
| --- | --- |
| 登录提示验证码错误 | 验证码为**一次性**且**5 分钟**有效，输错后图片会自动刷新，请重新输入；不区分大小写 |
| 登录提示账号锁定 | 连续输错密码 **5 次** 会导致账号被锁定 **30 分钟**，页面会提示解锁时间；也可联系管理员处理 |
| 忘记密码 | 系统不提供自助找回，请联系管理员在「会员管理 → 重置密码」中重置为 `Abcd@1234` |
| 注册时提示"该用户名/手机号/邮箱已注册" | 用户名、手机号、邮箱在系统中唯一，请更换或直接登录 |
| 注册时"统一社会信用代码校验不通过" | 请核对 18 位代码与校验位是否正确（按 GB 32100-2015 规则校验） |
| 无法发起入会申请 | 单位会员需先上传组织机构证、个人会员需先补全姓名与身份证；已通过审核或已有待审核申请时也不可重复提交 |
| 上传申请表失败 | 请确认扩展名在白名单内（jpg/jpeg/png/gif/webp/bmp/pdf/doc/docx/xls/xlsx/txt/zip/rar）且单文件不超过 10MB；图片/PDF/压缩包还会校验文件内容与扩展名是否一致；上传接口限流约 20 次/分钟/IP，频繁重试会命中"请求过于频繁" |
| 上传说"文件内容与扩展名不符" | 文件真实类型与扩展名不一致（如把网页/脚本改名为 .png），请上传原始文件 |
| 审核通过被拒绝，提示"机构尚未配置会员等级" | 请先在「组织机构」中为总会（或该申请机构）勾选「关联等级」，再重新点通过（全新部署会由种子数据自动关联全部等级，一般不会出现该提示） |
| 会费已缴但无法申请开票 | 开票上限取"实缴金额"。通过「免缴确认」置为已缴费的记录实缴为 0，属免缴语义、不可开票；如需开票，请管理员在「会费管理」中对未缴记录用「确认缴费」填写实收金额 |
| 会费金额不是预期的数字 | 全新部署会为每个等级自动建一条**当年**会费标准，金额为占位值 **2000 元**；请在「会费标准」中改为实际金额（只影响之后新建的费用记录，已有记录需在「会费管理」中改） |
| 证书无法下载 | 仅"正式会员"可下载；证书 PDF 未生成时请联系管理员在「证书管理」中生成或"补生成缺失证书" |
| 点「刷新」提示"当前已有生效证书，无需重复续证" | 该会员名下已有有效证书且 PDF 正常，无需重新发证；若确需换发（如信息变更），请管理员在「证书管理」中对目标证书「重新生成」 |
| 文章发布后看不到 | 文章需管理员在「文章管理」中审核通过后才会公开；已发布文章再次编辑会回到待审核 |
| 会费统计卡数字与"共 N 条记录"不一致 | 统计卡按**年度+会员类型**聚合（不受缴费状态筛选与分页影响），而“共 N 条记录”是当前筛选条件下的列表总数，两者口径不同属正常 |
| 证书 PDF 中文显示异常或未生成 | 服务器缺少中文字体文件，请运维按部署文档配置中文字体（TTF/OTF） |
| 管理员忘记密码 | 由另一位管理员在后台重置；若已无可用管理员，需直接处理数据库（密码为加密存储，无法反推） |

### 7.2 注意事项

1. **上线前必须完成的配置**（否则会员无法完成入会缴费闭环）：
   - 「组织机构」的**关联等级**与「会费标准」的**当年金额**会由系统**自动补齐默认值**（每个等级 2000 元），**请务必按实际情况核对/修改**，否则会按默认金额收费；
   - 「证书管理 → 证书样式」按等级上传 PDF 模板（可选，未配置时使用默认版式）；
   - 「系统管理」把站点名称、版权、ICP/网安备案号、联系电话/邮箱、协会收款银行信息替换为真实值（初始为 `XXXXXXXX` 占位内容）。
2. **默认密码务必修改**：初始管理员 `admin` 的密码为 `Abcd@1234`，且后台重置密码也使用该值，请首次登录后立即修改。
3. **会员到期与证书有效期**：系统**没有**自动到期任务，会员"已过期"与证书过期需人工处理；管理员可在「会员管理 → 状态变更」中置为已过期或恢复会籍（两者都会写入会籍记录）。置为"已过期"时会同步作废其生效证书，恢复会籍后需会员自行续证。
4. **删除是不可恢复的**：本系统为物理删除（无回收站），删除会员、文章、公告、费用、机构、等级等操作都会直接从数据库移除，请谨慎操作。若目标记录已被其他页面删除（或链接已过期），删除/操作时会提示"XX 不存在"（如"公告不存在""留言不存在"），刷新列表即可。
5. **会员资料变更留痕**：会员在"我的资料"中的每次修改都会按字段记录到「资料记录」，便于审计与追溯（密码不记录）。
6. **上传文件的访问权限**：上传目录为公开静态目录，请勿上传含敏感个人信息的文件（如身份证复印件）到公开渠道；正式环境建议由运维限制访问或改为受控下载。
